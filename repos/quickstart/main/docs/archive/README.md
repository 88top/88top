# 历史归档

这里保存过去的方案、调研、里程碑和验证记录，供维护者追溯。文件中的“当前”“已完成”、
版本号、测试设备状态与授权记录均属于当时的上下文，不代表当前版本、发布承诺或新的操作授权。
现行开发说明以[项目文档](../README.md)和源码为准。

| 位置 | 内容 |
| --- | --- |
| 本目录的历史 Markdown | 设备管理方案、阶段计划、交接和研究材料 |
| `product/` | 首页与设备页面的设计、评审和迭代记录 |
| `evidence/` | 历史验收摘要、工具输入和结果记录 |
| `prototypes/` | 早期交互原型，使用模拟数据 |
| `superpowers/` | 早期实施计划 |
| `CONTEXT.md` | 历史开发交接日志 |

外部产品比较与参考研究仅作为历史背景保留，不作为项目首页、功能清单或公开路线图。
归档不会移除文件或 Git 历史中的内容，也不提供访问控制；后续记录应使用虚构数据与占位地址。

历史覆盖矩阵的输入与输出一起归档。`make verify-product` 仍可检查引用并重新生成矩阵，
其通过只说明该历史清单内部一致，不代表当前发布验收。部分现有检查工具仍读取这里的样例，
移动或清理时需同步检查引用。
