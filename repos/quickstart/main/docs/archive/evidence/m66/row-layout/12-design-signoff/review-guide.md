## 建议实际确认的内容

| 顺序 | 操作 | 希望确认的产品感受 |
|---|---|---|
| 1 | 默认普通态查看首屏，再滚动全页 | 网络区比例、留白、卡片对齐与信息密度是否美观；原曲线特色是否保留 |
| 2 | 比较默认、三列、左右堆叠 | 结构是否容易理解；紧凑摘要和大卡的视觉层级是否协调 |
| 3 | 打开应用与工具、系统工具及软件中心入口 | 常用应用、维护工具、安装更新是否清楚且不冗余；页脚入口可找回 |
| 4 | 查看局域网设备，点单台设备及查看全部 | 名称、图标、品牌、在线状态是否好认；深入入口是否清楚；无DHCP权提示是否准确 |
| 5 | 点击自定义首页，切换行模板、比例、行高、上下比例 | 是否容易控制；尺寸不足提示是否能理解；普通态是否足够干净 |
| 6 | 移动行、交换卡片、隐藏再找回；取消/撤销/应用/恢复推荐 | 是否能放心试；隐藏全部后是否仍能恢复 |
| 7 | 缩窄至平板、手机，再回宽屏 | 手机阅读顺序和独立卡高度是否合适；宽屏结构和比例能否恢复 |
| 8 | 切换深浅色、加载/空/错误/缺服务/旧版本等场景 | 视觉是否一致，错误和缺能力时是否仍能理解并操作 |

卡片拖动适合当前可见区域；跨屏、触屏或键盘可用卡片选择器移动/交换。整行上移/下移有按钮。列宽和上下分隔线支持指针与键盘；最小尺寸不足时会阻止修改并说明。三列或堆叠只在空间足够时同排，窄屏按列内顺序展开，不随意补洞。

应用只保留当前预览内存：进入合成设备详情返回仍在，刷新恢复URL示例。切换布局示例或语言会重新加载，请先应用或取消草稿。本次未实现账号/路由器偏好保存，也不触碰真实设备。
