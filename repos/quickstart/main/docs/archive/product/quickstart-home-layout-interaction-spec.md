## 1.5 统一边界操作

R37～R40替代R33及旧版本中禁止手动行高／上下分配的部分，其他业务与布局语义沿用。

**R37｜默认自动，按边界直接调整。** 选中行时显示左右列宽手柄、堆叠两卡之间的上下分配手柄、行底边的空间手柄。上下分配只在当前行高度内移动，不在碰到最小值时自动拉高行；需要更多空间时由用户拉行底边。默认不预留额外空白。最小处就地提示，可拉高整行，不弹确认框。行布局面板只有一个“恢复自动高度与分配”，不增加数字表单。

**R38｜保存意图，内容优先。** 新增可选行最小高度与列内上卡占比；旧height/split仍仅作兼容资料，不自动激活。内容自然最低高度由当前DOM派生，不写入文档、形态、列表容量或历史。实际行高不低于内容；上下占比只在两卡最低需求之间钳制，缩窄或内容增长不覆写保存的占比。原型手动最小高度上限1600px，超过上限的自然内容仍完整展开；边界约束不裁内容。镜像时分配跟随列，整行排序完整保留，重建结构保留行空间意图但丢弃不再适用的列分配。

**R39｜共同草稿与手势。** 鼠标／触摸／键盘使用同一尺寸解析；手柄最小44px。左右手柄用左右键，上下与底边用上下键；Escape、失焦、取消指针、环境改变取消未提交手势。一次拖动提交一次历史，空操作不写。恢复自动一次可撤销；整页取消恢复进入前文档。编辑业务inert、移动及排序和尺寸手势互斥。

**R40｜响应式与有界测量。** 控件实际拆成单卡后，隐藏失去意义的分隔线和行空间手柄，不应用宽屏尺寸意图，宽屏恢复。普通浏览隐藏全部手柄。测量不创建业务组件或新轮询，只在已有数据／宽度／文档变化后合并执行，卸载清理；图表拉高时真实绘图区适配。原业务能力和数据采样边界不变。

1.4以R31～R36替代下文1.3中“上下仅摘要／图表任何组合固定高度”的限制。新规则是当前产品目标，实现进度单独记录，不以规则已经写入等同原型通过。历史1.0～1.3场景与证据不改写。

## 1.4 结构、形态与空间分配

**R31｜位置不强制信息量。** 行结构仅决定槽位，用户文案为左单右双／左双右单，保留left-big/right-big内部ID。形态独立解析；首批上下支持连接standard/summary、接口standard/summary中的summary，以及系统／共享／Docker／下载／远程的summary。接口standard和其他模块完整形态暂不据此开放；每种形态有明确位置能力、最低宽度、内容边界和伸展能力。上下调换或镜像不根据上／下位置强制改变形态。连接standard就是完整原连接信息，不增加重复full枚举。

**R32｜自动与兼容。** 新规则版本2的连接auto推荐standard；接口在上下位置auto推荐紧凑端口，其他已支持模块auto仍按模块／宽度／位置声明。明确偏好始终优先。布局文档升级v3，旧rows/v1迁移后保留auto并标记旧推荐版本0（普通系统auto完整），v2标记版本1（系统窄槽auto紧凑），不将auto改成显式summary；旧版本接口摘要仍保留计数外观。旧文档显式形态、ID、顺序、列宽及兼容资料保留。用户在显示设置主动选择形态／auto时采用新推荐版本，现有恢复推荐采用新偏好并进入一次可撤销的草稿变化；不因加载升级静默改造整页。未知版本拒绝并保留原输入。

**R33｜内容高度与伸展。** 上下两卡先按有限内容确定自身需求；紧凑卡保持自身内容高度，可伸展的标准连接承担剩余空间。两卡都不可伸展时可均衡分配剩余留白；不裁切内容、不恢复手动行高／上下比例。图表普通布局保留320px／手机300px视觉基线；新规则的左右上下组合中，真实绘图区随整行增高，不能只拉外框留空。整组仍沿用旧规则时保持历史固定绘图区；成员被用户主动采用新规则，或明确标准连接移入后，组合可以适配高度，不改写图表本身的推荐版本；撤销恢复旧外观。内容量、形态和采样不依赖测得高度；未知组合不一概开放。阈值和组合范围以当前实测为准，不凭任意像素上限裁切内容。

**R34｜单一计划。** 添加、移动、替换、拖放、改结构、调宽、显示设置和完成整理共同消费同一解析与计划。自然换行／增高不额外确认；必须改变明确形态才在现有影响预览确认一次。结构面板已给出完整影响时直接采用这一计划，不再重复弹出确认。来源留空、目标隐藏、模块唯一、空位整理范围与编辑业务inert保持既有规则。

**R35｜两视图与响应式。** 总览标注实际形态，缩略高度不参与解析；共用草稿／历史，不创建业务采样实例。窄屏按列内顺序拆行，保留明确形态，变宽恢复原布局。排序只改行序；取消恢复完整文档，撤销一次恢复位置／偏好／属性及推荐版本。resize或失效手势取消待提交动作，重算派生高度不写历史。

**R36｜业务与验收。** 网络连接保留原首页完整字段及动作；新紧凑端口最多2项，直接呈现名称、状态、已知速率，并可进入原端口详情／完整清单。旧摘要版本保持计数外观。失败、加载、空、缺能力和无权限局部呈现，不改变布局或模块身份。原业务、字体、标题入口、共享快照和资源边界不变；技术、设计者审图和用户体验分别记录。

| 操作 | 结果／确认条件 |
|---|---|
| 添加／迁移 | 按形态能力放入；无需改变意图则直接采用既有选择确认，不额外确认高度 |
| 替换／隐藏再添加 | 模块自有偏好保留，来源留空、目标隐藏、不交换 |
| 上下调换／镜像 | 形态跟随模块，不因槽位上下发生降级 |
| 改结构 | 保留模块和形态；缩槽按既有保留项预览；确需形态适配在同一预览中明示 |
| 调宽 | 正常换行并自然增高；明确形态不改变；不支持时拒绝或给明确替代 |
| 显示设置／恢复推荐 | 子预览，采用才提交；升级推荐口径有一次可撤销记录，关闭不写 |
| 空位整理 | 沿用既有保守范围，不跨行补洞、不暗中开放新结构 |
| 总览／排序 | 同一草稿，形态可识别；排序只变行序 |
| 撤销／取消 | 一次还原位置、形态、属性及推荐版本；整份取消恢复进入前文档 |
| 响应式／数值更新 | 派生呈现不写文档和历史，明确形态保留 |

## 3. 术语

| 术语 | 含义 | 不应混用 |
|---|---|---|
| 模块 | 网络流量、应用与工具、局域网设备等首页业务单元，按稳定模块ID唯一识别 | 显示名称不是身份；模块不是某一台设备 |
| 行布局 | 一行的槽位结构：单列、双列、三列、左大右上下、左上下右大 | 不是响应式临时拆出的可视行 |
| 槽位 | 行布局中容纳一个模块的位置，堆叠列包含上下两个槽位 | 空槽位不是加载失败或缺少服务 |
| 展示规格 | 模块的完整、标准、紧凑呈现，规定主次信息和入口 | 不机械等同100%、50%、33%宽度 |
| 展示形态 | 展示规格的后续统一产品称谓；具有明确信息层级与内容结构 | 不是把相同内容等比例缩小；大中小仅作辅助标签 |
| 显示属性 | 某模块形态内部可调整的有限选项 | 图标目标行数不是行布局的列数；不直接拥有整行高度 |
| 显示偏好／实际呈现 | 用户保存的形态与属性／当前容器解析出的结果 | 临时窄屏结果不写回偏好 |
| 布局适配能力 | 模块支持哪些展示规格、最低可读宽高、能否进入上下组合 | 不等同路由器是否安装限速等业务能力 |
| 草稿 | 本次编辑尚未完成的完整布局 | 不改变已应用布局 |
| 隐藏 | 从首页移除模块，保留模块设置，仍可找回 | 不删除应用、设备、服务或策略 |
| 整理空位 | 完成前将有空位的结构转换成明确、合法的简化结构 | 不跨行补洞，不自动交换 |

## 4. 布局与适配契约

**R01｜结构与唯一性。** 保留有序行 → 1～3列 → 槽位的固定层级；上下组合仅允许一侧两个槽位，不递归嵌套。全页每个模块最多出现一次。模块移动或改名不重建业务身份。普通并排外框等高；上下两卡高度加间距等于相邻大卡高度。比例按扣除间距后的右侧内容宽度计算。

**R02｜模块适配。** 每个模块登记展示形态、最低宽高和上下组合支持情况。选择列表按“可直接放入／明确调整后可放入／没有合法方案”区分；仅第三类禁用，说明具体原因并提供修改结构或位置的路径。第二类保持可选，预览必要变更并取得一次确认后提交，详见R20／R21。不能仅写“不可用”，不能将服务缺失当作布局不适配。历史M66.25只按当前行高禁用；当前M66.29已接入三类协商，实际证据看本轮验收。

优先定义最低可用空间，不轻易定义最大宽度；槽位更宽时用合理排版和留白保持美观，不无限放大图标或文字。规格必须有实际内容设计，不用裁切标准内容冒充紧凑摘要。若存在硬性限制，整理空位及所有输入方式都须遵守。

以下是首次改造范围，不是尺寸实测通过表；各规格的具体阈值在M66.19登记、M66.20及M66.24用真实容器校准。

| 模块 | 展示规格设计范围 | 本轮上下组合 |
|---|---|---|
| 网络流量 | 完整／标准，保留原曲线主视觉 | 不支持 |
| 网络连接 | 完整／标准／紧凑摘要 | 支持 |
| 应用与工具 | 完整／标准／紧凑启动网格 | 不支持上下摘要；紧凑网格不等于148px摘要 |
| 局域网设备 | 完整／标准，有界摘要和完整管理入口 | 不支持 |
| 系统状态 | 完整／标准／紧凑摘要 | 支持 |
| 磁盘信息 | 完整／标准，有界摘要和完整清单入口 | 不支持 |
| 存储服务 | 完整／标准／紧凑摘要 | 支持 |
| Docker | 完整／标准／紧凑摘要 | 支持 |
| 下载服务 | 完整／标准／紧凑摘要 | 支持 |
| 远程域名 | 完整／标准／紧凑摘要 | 支持 |

规格由可用空间确定，不要求给用户增加一个常驻规格选择器。响应式拆行后允许展开标准呈现；宽屏时不适配某个槽位，不能靠手机拆行掩盖。窄屏编辑使用逻辑结构预览表达桌面位置，不能简单禁用所有多列布局。

## 5. 主路径：真实页面中的槽位编辑

**R03｜入口和状态。** “自定义首页”默认在真实页面建立草稿，显示紧凑工具条。行边缘提供布局入口；空槽位提供“添加模块”，已有模块提供“替换”“从首页移除”。仅当前行或选中模块展开相关操作；普通首页不显示编辑外壳。整页布局总览是次级入口，不作为进入编辑的必经步骤。

编辑时业务跳转受保护：点击应用或设备不能误离开草稿。正常浏览态的打开应用、查看全部、单设备详情继续可用。设计场景、语言、主题等预览工具与产品编辑工具分开；左侧系统菜单及其区域不成为放置目标。

**R04｜新增与迁移。** 槽位选择器按目标适配能力筛选，展示模块名称、图标和首页状态。已有模块标记“已在首页 · 移到这里”及来源摘要；不得只禁用为“已添加”。确认前不清空来源。以下规则同时适用于真实页面和总览：

| 目标 | 选中模块A的状态 | 一次提交的结果 |
|---|---|---|
| 空槽位 | A未展示 | 在目标添加A |
| 空槽位 | A已在别处 | A移到目标，原槽位为空 |
| 已有B | A未展示 | A替换B，B隐藏并回到可添加列表 |
| 已有B | A已在别处 | A移到目标，原槽位为空，B隐藏并回到可添加列表 |
| 已有A | 选择自身 | 无变化，不增加撤销记录 |

**R05｜替换与隐藏。** 替换前展示来源、目标和被隐藏模块，例如“A将移到这里，B将从首页隐藏”。取消选择无副作用。隐藏保留模块设置和常用项；布局撤销还原位置，不回滚独立的业务设置。不能将替换解释为交换。本轮不设置独立交换入口，未来如增加，必须显式命名并单独验证双方适配。

**R06｜改变行布局。** 五种结构均有图示和真实结果预览。扩大槽位保留已有模块并增加空位；不自动从其他行取模块。减少槽位时明确展示保留项及隐藏项，由用户确认，不自动隐藏或移到后续新行。确认前保持原草稿；取消还原。单纯镜像上下组合保留原大卡和堆叠角色；其他结构转换按原列优先顺序形成候选，用户可调整保留项及目标槽位，并验证宽度和紧凑能力。1.3按R26自然增高，不再要求接受像素行高建议。

## 6. 空位、完成与恢复

**R07｜编辑中保留空位。** 移动、移除或改结构留下的空槽位和空行在编辑中保留，不立即收缩，不主动把其他模块滑进来，方便用户继续填入。模块数量不足不等于动作失败。空槽位须与加载、空业务数据和错误状态视觉区分。

**R08｜完成前整理。** 点击“完成”时先计算完整草稿的整理结果；存在结构、比例或显示规格变化时展示前后预览及受影响模块，确认后再应用。没有变化时不额外增加确认步骤。

普通行的规则：

1. 空行移除；普通三列仅剩两模块时按原列顺序变成等宽双列，仅剩一个时变成单列；双列仅剩一个时变成单列。
2. 规格随最终宽度和槽位角色重新检查，不能因展开反而裁切或违反硬性限制。1.3按内容自然增高并同排等高，不再用旧行高阻止展开；需要改变显式形态时仍明确预览并确认。
3. 没有空位的行不重置比例；不同逻辑行不合并、不跨行补洞。
4. 上下组合只有一整个列为空、另一列恰好一个模块时，可预览简化为单列；其他有空槽的上下组合，本轮不猜测新结构，定位到该行请用户选结构或补齐。
5. 无合法简化结果时不提交半成品，保留草稿、已应用布局和可撤销历史，明确定位问题并提供补齐／换结构／移除路径。不无限弹出确认，也不静默隐藏更多模块。

应用后不保留意外空槽。以上保守规则是本轮默认处理方式，未来扩大自动整理范围须新增明确的前后场景。

**R09｜原子操作与恢复。** 一次添加、移动替换、结构变化、整行排序或成功尺寸手势只记一步撤销；移动替换涉及多个位置，也必须一次撤销完整恢复。取消、自身目标、拒绝和仅预览不记历史。撤销最多30步。完成前的整理预览取消时恢复原草稿；完成更新本次内存布局，下一次编辑以该布局为起点；取消整个编辑恢复进入时的已应用布局。刷新仍恢复URL示例，不宣称存入账号或路由器。恢复推荐同样先改草稿，可撤销或取消。

## 7. 次级路径：整页布局总览

**R10｜同一草稿的另一种呈现。** 总览采用保留名称、图标、左右比例及上下关系的紧凑缩略卡，压缩高度便于看全结构，不是假装真实渲染比例的截图。支持模块和整行移动、添加、隐藏、改变结构；可定位回真实页面。切换视图保持草稿、选中对象及撤销记录，不额外保存。

模块放入已占槽位仍按R04/R05移动替换，不默认交换。若通过边缘插入创建新槽位，必须明确预览目标行结构、次序、比例和高度；只允许适配的普通单／双列扩成双／三列。已经三列或上下组合时不隐式扩容、递归拆分；给出新行位置或引导改结构。行间插入只新建单模块行；移动整行只排序，不改变其内部结构。源位置依R07留空，完成时依R08处理。

不能以左右边缘悬停猜测上下组合。屏幕内只强调当前目标，避免全页卡片同时覆盖落点说明。模块拖动仅为快捷方式，选择来源后点击目的位置和键盘路径必须可完成同一任务。

**整行排序（1.1补充）。** 总览行标题左侧提供“⠿ 第N行”手柄，纵向拖动整行；超过6px才启动，单击只选中。整行浮起、目标显示同高占位，相邻行让位；预览不写草稿，松手提交一个排序动作，只改变稳定行ID的次序，不改变内部模块、结构、比例或高度。原位松手、无效落点或中断均不记历史。

移除整行“选择目标行／目标列表”的移动模式；模块槽位移动保留。行内“···”提供上移／下移／置顶／置底，手柄支持Alt+上下及Alt+Home／End；均调用同一排序命令，焦点跟随原行。跨屏拖动在右侧内容上下边缘自动滚动，最高720px/秒，松手或取消即停止；正文触摸滚动不被手柄以外的区域接管。Escape、失焦、pointercancel、resize、切换视图／面板及卸载清理排序，草稿变化时拒绝旧手势提交。验收编号独立为RS01～RS08，见[M66.25任务树](quickstart-home-row-sort-m66-25.md)。

## 8. 互斥状态与尺寸调整

**R11｜一次一种动作。** 基本状态为正常浏览、真实页面编辑、布局总览；编辑子状态为闲置／选中、选择模块、结构设置、移动、调宽、调高、完成前整理预览，活动动作互斥。

| 事件 | 规则 |
|---|---|
| 切换真实编辑／总览 | 取消未提交动作，再保留草稿和历史切换；不提交半个手势 |
| 打开模块或结构面板 | 先结束未提交动作，仅保留当前面板；关闭恢复打开者焦点 |
| Escape | 先取消当前动作，再关闭面板；不直接丢弃整份草稿 |
| pointercancel、失焦、resize或目标失效 | 取消未完成手势，恢复手势前草稿，清理监听器 |
| 卸载 | 清理动作、浮层和读取任务；不自动完成草稿 |
| 切换语言／布局示例 | 明示刷新影响，先完成或取消编辑；数据场景切换只取消活动动作，不改布局 |

**R12｜尺寸操作（1.3修订）。** 保留列宽分隔线、预设及键盘操作，三列只调整相邻两列，合计100%。普通行高度和上下空间自动计算，移除手动行高、像素值和上下分隔比例控制；图表自身可视高度保持。总览只负责结构与位置，缩略尺寸不参与真实布局。调宽与移动互斥。具体见R26／R27；旧版手动高度断言仅作为历史保留。

## 9. 响应式、应用与业务状态

**R13｜三个布局层次分离。** 外层逻辑行有序，响应式按连续顺序拆行，不做dense填空。列内上下按列优先阅读；视觉、DOM和键盘顺序一致。窄屏展示不写回行结构、比例或模块位置，变宽恢复原偏好；调窄仅用于显示，不制造新的逻辑槽位。手机以点击路径完成全部核心任务，总览仍能表达原逻辑组合。

**R14｜应用与工具是普通模块。** 允许整行、半宽、其他合法比例；以实际容器宽高判断内部列数与完整可见行数，不再依赖“整行152px／并排240px”这样的模板特例。首次候选须提供可访问的半宽示例，默认首页的最终组合仍通过视觉评审确认。

应用入口保持用户顺序，图标和名称为主，描述按空间减少；不靠裁掉可读名称维持密度。M66.57修订：最多保存24项，默认八项依次为内网配置、终端、固件更新、DNS配置、软件源配置、开启沙箱、日志查看、系统维护。默认仅用于无记录或主动恢复，已有收藏不覆盖。系统工具、已安装应用及内置功能共用稳定ID收藏，不以名称或URL去重。空间不足显示完整可见行，并以“全部”承接，不静默丢项、不自动改序，不增加内部滚动条；安装或目录刷新不自动收藏、不拉高整行。若连一个可点击入口和必要标题都无法容纳，槽位应判为不适配。“全部”区分系统工具、已安装应用及内置功能，软件中心负责安装更新。目录失败、加载、无权限为未知，不当作卸载；已卸载或未知收藏保留原位并解释，由用户移除，禁止自动安装。隐藏首页模块不删除功能。

**R15｜业务语义及局部降级。** 首页设备与完整页共用同一库存、deviceId、图标、状态和权限含义；在线不等于允许联网，缺限速服务不隐藏设备列表。无DHCP分配权时引导到分配地址的主路由，不能用“旁路由”标签代替判断。加载、业务空、失败、旧版、缺服务和无权限只改变模块内容，不自动隐藏或重排模块，保留局部可用功能及合理重试入口。布局适配失败与业务能力缺失使用不同说明。

**R16｜读取与交付边界。** 两种编辑视图共用布局与读取协调器，不因切换、缩略图或移动复制组件采样任务；可见集合不变不重建读取。保留原图单一5秒采样、其他既有30／60秒周期、日志≤120、隐藏／卸载清理；总览的缩略曲线不得另启采样。无真实路由器写入或新增无界统计。当前候选技术自检、设计者审图、用户易用性／美感确认分别记录，不以历史证据或HTTP 200代替当前交互验收。

## 9A. 模块形态与显示设置（1.2新增，原型技术检查通过）

**R17｜一个业务模块，多种展示形态。** 身份、库存、状态、权限和完整功能入口保持统一。完整／标准／摘要可以具有不同内容结构，不与整行／半行／三分之一机械绑定；每个模块只开放真正设计和验证过的形态，不强行凑三档。新增设备摘要不自动意味着开放上下组合；位置类型仍单独验证。原NetworkFlow主视觉保持。

**R18｜形态与显示属性分离。** 启动条／图标网格是应用的形态；图标目标行数是网格内的属性，不复制业务模块。M66.57修订：自动模式标准半宽八项为4列×2行，手机为2列×4行；自动桌面最多3行，实际宽度不足三列的窄卡最多4行。保留显式单／双／三行及启动条，旧六项双行仍为3列×2行，三行为2列×3行。条目少时均衡排布、不造空项；最大列数6，实际列数由容器可读宽度决定。显示容量与24项保存上限分别计算，超出通过“查看全部”访问，顺序和内容不因形态、缩屏或目录变化修改。2026-10-19用户修订：标题按钮不附加“还有N个”，避免挤压标题；完整库的条目与计数保留。有限显示规则先于高度测量，不以实时数据或测得高度反向增加内容。

**R18A｜直接编辑快捷入口。** 更多→编辑快捷入口，先看到真实网格草稿，再从分类库添加。拖动手柄支持鼠标／触摸，键盘拿起后方向键移动、Enter落下、Escape取消；移除只移除入口，不卸载。局部撤销有界，恢复默认仅改草稿，保存才生效；取消、关闭及Escape均丢弃草稿。一次完整拖动只写一条撤销，中断不写入。布局编辑与快捷入口编辑互斥、草稿和历史独立；工具配置动作只在非编辑态打开，不在编辑选择中执行。

**R18B｜完整入口库与首页固定分离。** R14的模块身份和R18的首页形态不变；24项只限制首页固定ID序列。完整库合并系统工具、内置功能、安装应用及用户链接，同ID仅一项；默认全部，工具筛选包含内置功能。首页固定按原序优先显示，其他来源稳定排列，新项追加；目录刷新不修改首页序列，已保存但不可用的入口保留身份及原因。失败／未知不等于卸载；安装不等于运行。无有效入口不得生成跳转。单页最多48项，搜索完整库后再分页；不静默截断完整库。

**R18C｜用户链接与事务边界。** 原型会话最多64条自定义链接，稳定ID与名称／HTTP(S)地址分离；名称1～64字，地址最多2048字，拒绝控制字符、凭据及非HTTP(S)协议。内置图标，不抓取外部图标或探测服务；疑似同地址提示已有入口，不强制合并。新增默认不固定，显式固定受首页24项约束；编辑保留ID和位置。取消固定只改首页；删除链接及其首页引用为一次明确变更，删除前确认；恢复首页默认八项不删链接库。布局编辑、收藏编辑、链接表单互斥，表单保存原子提交，取消／Escape无副作用。原型只内存保存，刷新恢复示例。

**R18D｜启动台浏览与可访问性。** “全部”在右侧内容区打开宽浮层，系统菜单不变；默认图标＋两行名称，完整名称可访问。普通点击沿用原动作；自定义链接仅展示目的地址与新页打开说明，原型不访问目标。编辑操作按需显现，不增加第二套首页排序。顶部全库搜索／轻筛选，底部单一软件中心入口；单一纵向滚动及有界分页。桌面约6～8列、平板4列、手机2～3列，按实际可用空间调整；键盘、触摸、焦点圈定与返回均可用。加载、空、错误、无权限时其他来源继续可用。

保存或编辑链接后直接定位到该对象所在链接页并聚焦，包含第49项之后的入口；不让用户另行翻页确认保存结果，也不因此改变首页顺序。

**R19｜偏好与实际呈现分离。** 支持自动推荐与明确指定形态。按模块登记的稳定规则从偏好、属性、可用宽高与响应式上下文解析实际呈现；自动适配不修改保存值。用户指定形态在移动或替换时不得悄悄改为摘要；必要时给出显式方案。窄屏采用已登记的响应式呈现，变宽恢复偏好。形态切换保留其他形态适用的属性，不静默清空设置。

**R20｜共同高度（1.3修订）。** 先选形态及有限内容，再按当前宽度自然布局；普通同排取最大内容需求，上下组合按各自内容总高与间距分配。普通行不受旧像素高度或上下比例约束；旧“先确认增高才能放入”“减少内容不缩行”的规则由R26替代。形态／属性改变仍走一次事务；实时数字不能驱动内容容量，不能形成高度增长循环。候选阈值需实际验证。

**R21｜适配协商。** 添加、迁移、替换、拖动、改结构、改属性和完成前整理消费同一适配计划。三类结果为可直接放入、调整后可放入、没有合法方案。可调整项不能直接禁用；列明形态／属性／共同高度及被替换模块的变化，只进行一次影响确认。需要额外调整的拖放在松手后进入同一确认，悬停与待确认期间草稿不变；无需调整的动作保持已验收提交方式。无合法方案时不隐式扩列、挪走第三模块或开放未验证的上下组合。

**R22｜设置事务（1.3修订）。** 行“布局”管理结构和列宽；模块“显示设置”管理形态和有限属性。实际高度不写回文档。设置面板持有子草稿，预览不改变草稿、已应用或历史；采用将移动／替换及明确形态变更一次提交，撤销恢复完整文档，取消／失效不记历史。隐藏移动保留偏好；常用项内容与布局业务边界保持独立。

**R23｜统一契约及读取。** 模块定义集中声明形态、属性、允许位置、尺寸、溢出、状态和响应式规则；解析与规划不写状态或发请求，渲染消费同一解析结果。设备各形态复用同一deviceId、库存、在线／发现及DHCP权限语义；缺限速引擎仍展示设备。预览和切换形态不新建第二套采样／发现任务，总览缩略尺寸不用于真实尺寸判断。资源边界继续遵循R16。

**R24｜交付与正式开发。** M66.26～31先完成隔离Vue原型与当前候选验证，最终新形态体验由用户确认。正式实现复用模块定义、解析、变更计划、版本化草稿与共享数据契约；偏好持久化作用域、真实接口和迁移发布须另行确定及验证。本轮不宣称真实API、账号同步、安装包或设备业务已通过。后续架构参考与产品基线冲突时以本规范为准，并先修订相关文档。

## 10. 可复用的验收场景

**1.3历史规则（固定图表和上下限制现由1.4 R31～R36修订）：**

**R25｜系统信息形态。** `system`只有一个身份，summary为紧凑概览、standard为完整信息。自动按宽度和位置推荐，不能依据已算出的行高反过来改变形态。显式完整在普通窄槽自然增高，未验证的完整上下小槽仍不开放。共用数据、口径、完整字段与原信息概览入口。

**R26｜自然行高。** 普通行忽略旧height像素限制，按有限内容自然布局并同排等高；上下组合按自身内容分配，含间距与邻卡等高，旧split不约束实际高度。图表自身可视高度固定，不被兄弟内容拉伸；若兄弟指定完整内容更高，外框可以自然增高但曲线不随之拉长。窄屏拆行后重算自身内容高度。

**R27｜编辑简化。** 常规编辑移除行高拖动、行高档位／像素值和上下比例操作，保留结构、列宽、排序、显示设置、替换及恢复。自动自然增高无需额外确认；显式形态改变、缩槽保留项等仍需要同一影响预览和一次原子提交。新规则替代R06／R08中原“明确提高行高”步骤。

**R28｜标题区操作。** 至多一个主操作加必要更多菜单，原动作目标与表单保持。完整清单／连接详情等次操作归入标题菜单，不另设重复底部详情栏；底部必要状态／权限解释保留。所有入口支持键盘与触摸。

**R29｜兼容与有限内容。** v2原型文档兼容旧rows／v1，保留模块、顺序、列宽、偏好及恢复所需旧尺寸；普通行由content语义接管高度。首页投影有有限容量，数量及未显示异常有解释，完整详情不删字段或动作；切换形态不改原业务状态或真实存储。

**R30｜验证与边界。** 新实现重新验收五模板、尺寸阈值、两主题／语言、异常、真实输入、20次切换及后台／卸载资源；绑定当前源码和公开资源。技术通过与人工体验分开。任务及矩阵见[M66.38～43](quickstart-home-natural-layout-m66-38-43.md)，正式业务／安装包／设备验收不混入原型完成声明。
