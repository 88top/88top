# 快捷启动台人工体验卡

当前入口：[默认首页](http://192.168.9.19:5180/?layout=ordered)。只修改右侧Quickstart内容；左侧是系统菜单占位，不是菜单改版。

1. 首页第二排“应用与工具”默认八项，应与设备列表同排；桌面4×2，手机2×4，保留原字号、轻量图标与连体“全部／更多”。
2. 点更多→编辑快捷入口。在已安装应用页签选择Docker或其他应用；向上滚回预览，抓住手柄拖至第二位，再移除一项、撤销、保存。再次打开应保持顺序。
3. 用键盘空格拿起图标，方向键／Home／End移动，回车放下；Escape先取消拖动，再按Escape取消编辑。手机直接抓手柄拖动，其他区域可滚动。
4. 恢复默认八项后先取消，再重做并保存，体验不同的事务结果；移除全部入口允许保存，可从空状态重新添加。切换到“自定义首页”应是另一份独立布局草稿。
5. 编辑中缩小窗口或切到手机宽度：只取消未结束的手势，面板／已有草稿仍保留。关闭后焦点返回可用入口。
6. 点“全部”体验工具／应用／内置分类与搜索；软件中心只承担安装管理入口。工具配置仍使用原表单，终端／固件／日志／维护显示原业务目标；预览不会打开真实服务或执行网络切换、沙箱重启。
