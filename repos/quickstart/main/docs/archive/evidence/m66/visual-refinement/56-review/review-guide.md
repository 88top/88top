# 人工审美体验

本轮保留原卡片、五行默认布局和自定义交互，只精修原型视觉。当前技术进度见[总状态](../status.md)；人工体验尚待用户确认。

入口：[默认首页](http://192.168.9.19:5180/?layout=ordered)；[全部服务运行的合成数据](http://192.168.9.19:5180/?layout=ordered&scenario=business-all)。旧`preset=services`等链接仍是历史命名对照，请使用不带preset的入口看默认五行。

建议按以下顺序体验：

1. 先看整页：网络曲线仍是重点，卡片边界轻，系统型号与固件不再形成大色块。空白保留，没有新增无意义内容。
2. 看服务选项：存储／下载／远程的选中样式一致；选中与启用／停止是两件事，状态文字仍明确。
3. 看细节：标题连体按钮、设备名称和图标、应用图标底座、磁盘轨道与容量、路径容器是否协调。
4. 切深色／英文并缩到手机：标签和次级文字可读，标题操作不挤压，没有横向滚动或卡内滚动；系统按原规则采用摘要，完整信息入口保留。
5. 进入自定义：首页结构、模块移动／替换／隐藏、行排序、列宽／上下分配、撤销／取消仍与此前一致。布局只保留在本次预览，刷新恢复示例。

用户确认项：整体色彩是否舒服、状态是否清楚、内容密度是否合适、各卡是否像同一套产品。自动化几何与对比度检查不能替用户回答这些审美问题。
