# M66.43 人工体验任务卡

本轮技术自检已通过，**本轮人工体验待用户确认**。此前首页自定义布局的认可不能替代自然高度与系统双形态的当前体验。

入口：[默认首页](http://192.168.9.19:5180/?layout=ordered) · [六组件完整示例](http://192.168.9.19:5180/?layout=ordered&preset=services&scenario=business-all) · [左大右上下](http://192.168.9.19:5180/?layout=ordered&preset=stacked&scenario=business-all) · [应用与设备同排](http://192.168.9.19:5180/?layout=ordered&preset=apps-devices&favorites=6&scenario=business-all)。旧标签页请刷新；构建后预览不热更新。

| 体验任务 | 应看到的结果 |
|---|---|
| 默认首页浏览，缩窄再加宽窗口 | 同排外框等高，窄屏按顺序拆行；普通卡内没有滚动条，整页自然滚动 |
| 系统信息→自定义首页→齿轮显示设置 | 自动推荐、紧凑概览、完整信息；普通窄槽指定完整后保留全部原字段，自然增高 |
| 紧凑系统标题“⋮”→完整信息 | 同一原系统组件的三项图表、设备型号、固件内核、系统时间和已启动；关闭回到原位置 |
| 系统标题“信息概览” | 演示原`/cgi-bin/luci/admin/status/overview`目标；预览不会跳到真实路由器 |
| 左大右上下组合 | 两个小卡按内容分配上下空间，与大卡外框等高；网络曲线可视高度不被拉长 |
| 应用与设备同排，应用选择双／三行图标 | 应用可自然增高，同排外框保持整齐，无需填写行高 |
| 行“布局”及列宽调整 | 保留五种结构、列宽与真实预览；不再出现行高像素、上下比例及“接受增高”步骤 |
| 布局总览将第五行拖到第一行，再撤销／取消 | 整行及内部结构一起移动，一次撤销恢复；取消还原进入前的完整布局 |
| 网络连接、网络接口标题“⋮” | 连接详情和全部接口从标题可达；底部不再重复放详情按钮；设备管理／接口配置仍是原主操作 |
| [磁盘异常示例](http://192.168.9.19:5180/?layout=ordered&preset=services&scenario=business-disks) | 首页最多3项并提示其余异常；标题完整信息仍显示8项及原操作，原高级入口在同一菜单 |
| [24共享示例](http://192.168.9.19:5180/?layout=ordered&preset=services&scenario=many-shares)，切SAMBA | 首页2项并说明总量；标题完整信息可看到24项；原配置向导仍可用 |
| 顶部设计预览切系统失败、服务缺失、旧后端，或改为手机宽度 | 失败只影响有关模块；缺失限速服务仍可显示设备；标题菜单、关闭和触摸操作可用 |

所有设备、指标和提交都是合成内存数据，刷新恢复URL示例，未接偏好持久化。左侧仍只是不可编辑的系统宿主占位。产品规则见[规范1.3](../../../../product/quickstart-home-layout-interaction-spec.md)，技术结果见[42验收](../42-review/acceptance.md)。
