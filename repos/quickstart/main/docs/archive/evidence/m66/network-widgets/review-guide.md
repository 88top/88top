# 网络控件体验入口

[连接与接口独立示例](http://192.168.9.19:5180/?layout=ordered&preset=network-business)。顶部“设计预览”可切布局示例、数据场景和主题。全部合成数据，刷新恢复示例；以下供本轮新控件体验，不自动填为用户验收通过。

1. 分别查看“网络连接和IP地址”和“网络接口状态”。前者没有端口灯／端口清单；后者可看链路、协商速率和完整端口详情。
2. 分别显示IPv4、IPv6；它们独立计时60秒。进入连接详情读取完整字段，关闭详情后恢复隐藏；缺地址不显示“已关闭协议”。
3. 数据场景选DNS错误／软件源错误，打开对应原有表单。取消不写，确认仅写示例内存；也可切配置提交失败场景观察拒绝。真实网络和软件源不会修改。
4. 点击端口或用键盘Enter打开详情；“查看全部”访问完整列表。大量场景为128端口／48DNS，有分页而不撑大卡片；空和失败语义独立，失败不是“正在读取”。
5. 自定义首页中，两模块分别选择标准／摘要；手机摘要为176px，变宽恢复保存的行高。模块各自移动、隐藏、重新添加；撤销和取消应保持完整文档语义。
6. [旧默认布局](http://192.168.9.19:5180/?layout=ordered)不会擅自插入接口卡；从“自定义首页→添加模块→网络接口状态”可单独加入。设备管理进入隔离完整设备页，接口配置进入安全目的页；不代表真实路由器配置页面已验收。
