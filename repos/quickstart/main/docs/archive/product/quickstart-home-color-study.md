# 首页色彩增强候选

2026-10-20，用户要求将这套点彩逻辑应用到正式Quickstart web。这是当前正式配色规则：大部分界面淡雅，部分重要文字和图标本身有色彩，参考旧版Quickstart；不能主要靠加深图标和操作背景。保留已确认的布局、形态、字号、间距、业务入口、正式蓝色顶部和系统菜单边界。下列classic/bold仅为隔离预览对照，不进入正式产品设置。

## 三种对照

| 风格 | 方向 | 适用体验 |
| --- | --- | --- |
| 原版 classic | 已有低饱和蓝灰、浅图标 | 保留原设计作为相同数据和布局的对照 |
| 鲜明 vivid（当前推荐：业务点彩） | 中性浅灰画布、白卡片、浅底操作、彩色线条图标；服务名称、重要资料和读数采用业务色 | 大部分淡雅，少量彩色文字和图标增加生机 |
| 浓彩 bold（前轮对照） | 更浓的画布与选中面、实色蓝主操作、图标渐变 | 保留浓底方向作为比较，不再作为本轮推荐 |

默认预览为鲜明版。根地址http://192.168.9.19:5180/，或在“设计预览→色彩风格”中切换。URL参数palette=classic/vivid/bold只用于设计比较，不写入首页配置。导航保留此评审参数。

## 色彩职责

推荐方案恢复中性浅灰画布、白色卡片及淡边框；取消卡片色晕，不用浓底或白色线条作为应用图标的主要表达。图标本身使用清晰蓝/青绿/紫，容器仅保留很浅的辅助底色；普通标题操作使用中性文字和浅底，不批量染蓝。正文保持深灰蓝，辅助文字保持清晰对比。服务名称与其图标同色，少量重要资料和链接保留彩色，让页面的生机来自内容层级。正文、服务名称/状态及工具/服务图标与背景对比度≥4.5，覆盖服务悬停态；旧版部分亮橙等颜色按可读性调深同色相，不机械复制色值。原组件已有装饰性图形与图表保留自身业务表现，不以本轮检查冒称所有图形都经过重新取色。

对照用户截图和历史`da46bfa`的五份正式组件源码（[取色来源](../evidence/m70/design-color/semantic-accents/old-colour-sources.json)），采用以下映射。颜色用于业务身份，状态文字单独表达是否启用：

| 位置 | 身份/内容色彩 | 保留的语义 |
| --- | --- | --- |
| 下载服务 | 标题图标绿；Aria2橙、qBittorrent灰蓝、Transmission青绿 | 三个名称/图标有色，未启用文字仍中性，不将选中当作运行 |
| 存储服务 | 易有云蓝、SAMBA绿、WEBDAV紫 | 对应图标与名称一致，服务状态独立 |
| 远程域名 | DDNS蓝、IPv4绿、IPv6灰蓝 | 身份色不等于域名解析成功 |
| 网络连接 | 成功状态图标/文字绿；失败按原状态反馈 | 仅当前netSuccess显示绿色状态文字；接口在线时长继续中性并保留解释，不恢复旧截图中可能被理解为持续联网的绿时长徽标 |
| 系统资料 | 设备型号蓝、固件资料绿，与原图标呼应 | 属于资料身份色，不表示固件健康/升级可用；内核与辅助信息保持中性 |
| 网络读数/图表 | 下载蓝、上传紫，读数/图例对应 | 保留现有曲线、环形指标阈值及来源 |

卡片不恢复顶部装饰线；保留1px淡外框、轻阴影及已有间距。服务选中使用单层边框区分，不叠加内描边；键盘焦点继续使用明显外框。浓彩对照保留白字渐变图标，测试独立验证其渐变端点；不能把该对照的旧规则要求到推荐点彩方案。

连接在线/离线、端口状态、服务运行与警示仍由业务决定。绿、琥珀及中性色保持各自状态语义；选中服务不等于运行。图表内核、曲线采样、原有阈值不改；只沿现有令牌增强读数/图例。

分段主操作统一通过变量控制外框、底色及文字，菜单按钮跟随操作组；单独出现的摘要更多使用正常正文色，避免白字落到浅底。正文菜单恢复面板正常文字，不能继承白色主按钮文字。原业务组件设置按钮中明确的黑色单色路径在实验配色内跟随文字色，保留其他品牌/状态色和图形结构。

## 实施与检查

`home/homeSemanticColors.css`是正式首页和预览推荐方案共用的唯一点彩契约。正式HomeLayout和挂到body的NetworkWidgetDialog采用`home-semantic-colors`作用域；预览仅在vivid时采用同一契约，`design/homeColorStyles.css`只保留浓底方向与设计按钮适配。正式构建不导入设计CSS或配色URL开关。

服务名称/图标/未启用说明的规则同时覆盖首页与完整信息弹窗；对原组件明确的class范围校正优先级，避免名称被旧灰字或选中底覆盖。原组件的状态条件、业务字段和处理函数不改。应用品牌图片保持原像素/路径与失败回退；系统工具和链接使用现有图形及新颜色变量，不对品牌图标做滤镜或强制单色。没有配置结构、布局算法、业务表单或读取owner改动。

验收：三配色×中英×深浅×1440/1024/768/390/320，检查控件尺寸和文档与原版一致、左侧占位样式不变、正文/辅助/选中/状态/按钮对比度≥4.5；推荐方案检查实际彩色服务名称/图标/状态、工具图标及系统资料对比度，浓彩对照继续检查渐变端点。配色选择不修改布局，应用库/菜单/编辑/摘要行为可用。继续采用[已确认外观规范](quickstart-home-widget-visual-standard.md)的布局与交互规则；本提案不把全站低饱和基线擅自改成已确认结论。
