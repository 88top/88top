## 优化与失败记录

本轮可读性与初始化修正在原型实施阶段完成。验收阶段进行了三轮修正：

1. 网络监控的渐变背景使初版自动对比度读取错误，改为一致的实色面板和强调边框，避免额外背景对文字造成干扰。初始记录为 `initial-review-failure.json`。
2. 手机单列仍残留桌面跨列规则，产生隐式列并挤压设备区；明确所有手机模块跨同一单列。原始记录为 `responsive-review-failure.json`。
3. 样式隔离时 Vue 的 global 选择器丢失子选择器，深色实际上变成浅色。人工截图复核发现并修正；增加实际前景/面板配色断言。`pre-visual-gate-report.json` 保存当时自动化通过但人工未通过的记录，不能作为深色验收证据。

另外 `style-serialization-test-failure.json` 是测试错误比较 CSS 字符串格式，改为计算样式与实际宽度断言，未靠修改页面去迎合序列化格式。

最终 `report.json` 是修正后当前预览的复验，不覆盖上述历史记录。速率格式复用原首页工具，当前示例显示368.6KB/s与20.5KB/s。
