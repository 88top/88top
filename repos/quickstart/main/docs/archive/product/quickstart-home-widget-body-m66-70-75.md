目标：在既有布局和业务保持一致的前提下，让网络连接、磁盘信息、存储服务、Docker、下载服务、远程域名、系统信息的正文更整齐、清晰，适合日常浏览。共享视觉规则维护在[唯一外观规范](quickstart-home-widget-visual-standard.md)，形态与布局继续遵循[布局交互规范](quickstart-home-layout-interaction-spec.md)。本计划补充实施顺序与证据，不另建一套外观标准。

## 范围与保护边界

- 只修改隔离Vue设计原型及必要的展示适配。正式首页接入、真实设备、API、权限、持久化、安装包与长期观察不属于本轮验收。
- 保留左侧系统菜单、五行默认结构、行列顺序、宽度比例、形态选择、用户尺寸意图、上下分配、自动布局、拖动、撤销与取消。网络流量、网络接口、设备、应用四控件保持当前功能和展示；共享样式影响必须检查。
- 标题外框、前置图标与文字、连体更多、外层圆角和内边距沿用M66.69。改动集中于正文对齐、间距、信息分组、容器与视觉层级，不新增卡片右下角操作。
- 沿用原字体及标题16/14px、正文14/13px、辅助12px的现有字阶；重要指标只能使用已有指标字阶。正文使用8/12/16px间距节奏，不用缩小字号处理拥挤。
- 字段、状态文字、显示条件、权限、跳转目标、启停/安装/修复流程、自动选签与用户选签优先级保持。可点击地址仍可点击，只读路径保持只读。服务“已选中”与“已启用/已运行”分开表达。
- 保留原统计口径、颜色阈值和容量上限；不增加填空用的容器数、任务数或清单尾注。不顺带修复已记录的业务计算问题。
- 自然内容高度可随换行与内部留白调整，但由现有机制处理；不更改行结构、写回用户尺寸意图、制造卡内滚动或用任意固定高度掩盖问题。对比截图须说明高度变化原因；若需改变布局规则才能成立，作为产品决策停止。
- 业务脚本、请求所有者、轮询、缓存、图表生命周期与采样不变。优先复用现有`homeWidgetDetails.css`及主题令牌；必要模板展示改动列入显式允许清单，不用业务字符串解析或全局DOM扫描生成字段。

## M66.70：基线与正文契约

目标：先证明保留了什么，再确定哪些展示可以调整，避免视觉改动静默改变业务。

任务树：

1. 当前版本核验
   - 检查工作区、当前HEAD、5180进程归属和公开资源指纹；记录可复现的启动/构建方式。
   - 读取七控件当前模板、业务脚本、原型适配、摘要/完整形态及共享样式。
2. 业务与视觉盘点
   - 按字段、状态、条件、动作、权限、链接、读数单位建立保护表；覆盖下方状态矩阵。
   - 用相同合成数据记录桌面与手机原图、DOM、关键对齐坐标及字号，建立前后可比样张。
   - 列出允许改动的展示文件；原业务脚本及布局/请求/图表代码生成保护指纹。
3. 共享规则收敛
   - 在唯一外观规范中补充正文规则：键值行、状态行、服务选项、只读地址、信息面板与空白。
   - 定义可比较的对齐基线、长文本处理、主题与焦点规则，不预先搭建通用业务注册框架。

验收标准：

- 七控件及其当前支持形态都有字段/条件/动作映射；当前不可达动作不能列成已经可用。
- 每条视觉改动都有允许范围；64项既有原业务文件保护清单与新增必要展示例外分别记录，例外不能豁免业务脚本比较。
- 正常、未配置/未安装、加载/错误、长文本基线有可复现入口；原型不具备的状态显式标记并补充隔离fixture，不伪造当前支持。
- 对齐检查只比较同类元素：相同排版下基线偏差目标不超过2 CSS px；自然换行例外有明确规则，不要求不同业务内容等高或填充空字段。
- 本阶段不改变运行中的控件外观，基线来源与当前服务版本可核对。

目标：先把一张同时包含服务选项、状态、地址和目录的卡片做好，验证共同规则适用。

任务树：

2. 最小共享适配
   - 收敛重复间距、颜色、只读数据容器与字段标签规则，使用现有主题令牌。
   - 明确样式作用域，避免泛化`.item`、`button`或全局SVG规则。
3. 状态与操作自检
   - 验证三服务的配置/未配置、路径/端口条件、用户选签及刷新行为。
   - 核对可点击目录、易有云配置入口和服务URL；保留普通SAMBA地址的只读属性。

验收标准：

- 三个服务选项尺寸规则、名称/状态基线一致，选中态与运行态可分别识别，中文/英文均无裁切。
- SAMBA表头及内容各列起点一致；长地址/目录不横向撑破卡片，必要内容可读，原有链接目标和点击条件一致。
- 已配置、未配置及局部失败不被统一“正常”覆盖；自动优先选择与手动选签后的刷新行为不变。
- 桌面/窄槽、浅色/深色样张通过；字号不变、没有新增卡内滚动、标题及更多交互不变。
- 存储服务脚本/请求所有权保护通过，共享样式没有改变其余十控件的业务行为。

## M66.72：Docker、下载、远程域名统一

目标：让三列服务区有相同的阅读节奏，同时保留各自真正需要的字段和动作。

任务树：

1. Docker
   - 对齐状态标签、开关和状态徽标；根目录使用明确只读的信息容器。
   - 保留未安装/停止/运行/失败、提交禁用与失败恢复、迁移及条件高级入口。
2. 下载服务
   - 复用服务选项样式，统一状态、目录、Web入口与辅助说明层级。
   - 保留Aria2/qBittorrent/Transmission原入口、安装向导、AriaNg认证配置及远程下载帮助链接。
3. 远程域名
   - 保留各页签的状态与正文主状态，通过层级区分；域名与控制台动作对齐，长地址可换行。
   - 核对DDNSTO、IPv4/IPv6页签显示条件、Stopped/Disabled、在线判定及安全链接。
4. 横向比较
   - 对齐三卡标题和正文起点、公共字段间距与容器；Docker不增加空页签或虚构统计补齐高度。

验收标准：

- 三卡相同类型状态行、字段标签和只读容器使用同一规则；没有为了对称添加无意义占位。
- Docker启停成功、待提交、失败恢复及禁用条件通过；不启用已注释的容器数/镜像数。
- 下载三个服务各自的运行/停止、目录与Web入口条件通过；AriaNg目标及帮助链接保持可达，不将真实链接改为普通灰字。
- 远程域名原有状态字段全部保留，页签可见性及自动/手动选择行为不变；原控制台、配置和授权目标一致。
- 320px与英文长地址场景无重叠/横向溢出；原业务条件、处理函数和请求节奏保护通过。

## M66.73：网络连接与磁盘信息精修

目标：让地址与磁盘列表有稳定的阅读轴线，复杂状态下仍能操作。

任务树：

1. 网络连接
   - 对齐IPv4/IPv6/DNS字段及协议/隐私控件，接口运行时长采用较弱中性色阶，保留其准确含义。
   - 将长星号改为固定短圆点遮罩，仅改变隐藏展示，不改变地址值和隐私控制。
   - 核对完整/摘要/详情、DNS与软件源修复、旧快照/错误状态。
2. 磁盘信息
   - 统一名称、容量条、用量的起点与间距，组织稳定动作区域，避免条件图标挤压容量条。
   - 保留系统根目录/非系统盘/RAID分组与原字段，不从显示字符串解析新业务字段。
   - 覆盖SMART异常、未挂载/未分区、只读、局部失败、长名称与多条件动作。
3. 响应与保护
   - 窄屏必要时自然换行，不隐藏动作、不改首页有界清单、不恢复多余统计尾注。
   - 比较当前显示设置、行空间、原始快照与操作目标。

验收标准：

- IPv4/IPv6独立显示/隐藏、60秒自动隐藏及既有关闭/后台/重置行为通过；固定遮罩不泄露地址长度，显示后完整地址仍可读。
- DNS清单和原详情分页/入口保持，接口运行时长不被改成互联网在线时长；旧快照不显示为当前正常。
- 磁盘同类行对齐；条件动作增减不导致进度与文本互相覆盖；移动端可换行但仍可触达全部既有动作。
- 容量数值、原阈值颜色、SMART/RAID判定、格式化保护及原挂载/详情/菜单行为不变；异常分支不被普通进度条替代。
- 桌面与窄槽前后样张可对比，字号不变、无新增内部滚动，网络接口独立卡与图表保持原行为。
