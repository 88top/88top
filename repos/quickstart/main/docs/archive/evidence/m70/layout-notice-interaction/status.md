# 首页操作提示可关闭、自动收起与稳定布局

目标：取消/撤销/成功提示无需刷新即可关闭，普通提示3秒自动收起；保存错误和进行中状态不因定时器消失；所有提示不占内容流、不进入侧栏、不写布局配置。

任务树及验收：

- P1 共用提示状态与视图，正式/设计源码复用；重复消息重置生命周期，鼠标悬停/键盘聚焦暂停自动关闭，关闭按钮44px可触摸，卸载清理计时器与观察器。
- P2 取消/撤销/排序等为普通提示，校验或保存失败持续显示但可关闭，保存中关闭只隐藏消息、不取消保存。当前提示操作不改变草稿、撤销历史、保存并发语义或空行整理规则。
- P3 更新产品指导；独立类型检查、正式Web构建及针对实际触发路径的UI检查。先保留当前B缺陷红灯，再冻结候选并快速替换B前端。
- P4 当前B中英×深浅×桌面/手机检查关闭、自动消失、重复触发、焦点/触屏、内容位置和侧栏边界；错误/超时/成功通过浏览器拦截保存响应验证，不让测试保存实际到达路由器。资源、配置和会话清理复核。
