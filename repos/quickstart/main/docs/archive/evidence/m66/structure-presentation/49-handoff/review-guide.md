# 本轮体验任务卡

M66.44～49技术交付，本轮人工体验待用户确认。此前自定义首页的认可作为历史，不能替代这次混合形态的体验。

入口：[完整连接＋紧凑端口](http://192.168.9.19:5180/?layout=ordered&preset=network-stack&scenario=business-all) · [左右镜像](http://192.168.9.19:5180/?layout=ordered&preset=network-stack-mirror&scenario=business-all) · [端口在上／连接在下](http://192.168.9.19:5180/?layout=ordered&preset=network-stack-reverse&scenario=business-all) · [普通首页](http://192.168.9.19:5180/?layout=ordered) · [旧v2自动推荐示例](http://192.168.9.19:5180/?layout=ordered&preset=network-stack&legacy=1)。顶部设计预览可选择前三个新示例。刷新旧标签页加载当前构建。

| 体验 | 应有结果 |
|---|---|
| 第一行普通浏览 | 左侧原流量曲线，右上完整连接字段，右下直接看到端口名称、状态、速率；上下不强制均分，左右整体等高 |
| 三个组合示例比较 | 标准连接跟随模块，端口在上也不会自动成为大卡；左右镜像保留位置关系和形态 |
| 自定义首页→显示设置 | 连接可选择标准／摘要；接口可选标准／摘要，但上下位置目前只开放紧凑端口。适配失败有原因，不靠裁切通过 |
| 移动／替换到另一槽位 | 明确形态保留；来源留空、被替换目标隐藏，不能暗中交换；从空位重新添加保留自身设置 |
| 行布局→左单右双／左双右单，调列宽 | 标准连接可用；自然换行和增高不额外确认。确需改变接口形态时，在当前影响预览一次采用 |
| 布局总览 | 名称和形态分开，缩略高度不代表真实高度；返回真实页面仍是同一份草稿 |
| 拖动整行／撤销／取消 | 行内部位置和偏好保留，一次撤销一个动作，整份取消还原进入前状态 |
| 缩到手机再加宽 | 按列内顺序展开，明确选择的形态保持；auto可按普通位置展开；加宽恢复保存的组合，窗口变化不写历史 |
| 旧推荐示例→连接显示设置→点击自动推荐→采用 | 加载时仍旧摘要；采用后完整连接和图表一起适配，图表自己的偏好不被改写；撤销恢复旧外观 |
| 点端口、标题更多、设备管理和DNS错误动作 | 同一原详情、完整清单及原配置流程可达；只有合成内存操作，不写真实网络 |
| 设计预览切DNS错误、接口失败、没有接口、旧后端和缺服务 | 各模块局部呈现，失败不隐藏其他模块、不改变结构；没有限速引擎仍有设备库存 |

系统左侧仍为不可编辑宿主占位，不属于本次设计。所有数据及提交均为合成内存；刷新恢复示例，没有真实偏好持久化／账号升级验收。规范见[1.4 R31～R36](../../../../product/quickstart-home-layout-interaction-spec.md)，当前结果见[48验收](../48-review/acceptance.md)。
