# M66.13 交互契约

任务树：现有能力→状态→三类卡片落点/整行排序→统一命令→场景和输入路径。验收按M66.13计划，先定义再实现。

## 状态转换

| 状态 | 进入 | 可用动作 | 退出/取消 |
|---|---|---|---|
| 浏览 | 加载/完成/取消草稿 | 导航、进入编辑 | 进入编辑复制已应用布局 |
| 编辑未选中 | 进入编辑/点击空白 | 添加、选择卡/行、撤销、恢复、完成 | 取消恢复已应用布局 |
| 卡片/行选中 | 明确手柄点击/键盘 | 移动、隐藏/结构、尺寸 | 空白取消选择；选择其他对象替换 |
| 选择目标 | 点击移动/添加 | 合法目标点选、跨屏列表、取消 | Escape返回编辑，不丢草稿 |
| 指针移动 | 手柄移动超过6px | 目标轮廓、说明、浮层预览 | 放下确认；Escape/pointercancel/失焦/resize/场景变化/卸载取消 |
| 尺寸预览 | 拖分隔线 | 实时比例及限制 | 放下记一步；中断恢复手势前 |
| 临时面板 | 结构/模块/更多/目标列表 | 对应对象操作 | Escape先退出移动再关面板；关面板恢复打开者焦点 |

一次手势最多一个历史快照，无效、自放回原位和取消均零快照，最多30步。交互期间已应用布局保持不变。完成过滤空行再写入内存，取消草稿恢复已应用布局。刷新恢复URL示例。

## 动作结果与拒绝

- 卡片中心：交换源与目标，同时检查两端高度和紧凑契约。自己是无变化。隐藏模块不可通过交换覆盖已有模块。
- 空槽：移入，源留空；草稿可见空槽，浏览态隐藏空槽。空逻辑行保留编辑占位，完成时去除。
- 行间：卡片移出，新增独占逻辑行，高度采用该模块标准推荐值。拖整行到行间只改变逻辑行顺序；自己前/后是无变化。
- 添加：仅接受尚未显示的模块，目标为兼容空槽或新增行；已显示模块提供定位，避免重复。
- 模板：single[A]→pair[A,空]；pair[A,B]→triple[A,B,空]；triple[A,B,C]→single[A]+single[B]+single[C]；left-big[A;B/C]→right-big[B/C;A]；right-big[B/C;A]→pair[B,C]+single[A]。沿用现有模板展开顺序。
- 行高/比例：不改变未选中行；三列调整相邻两列保留合计；高度不足说明所需尺寸，不偷偷升高。compact只支持连接、系统、共享、Docker、下载、远程；图表/设备/磁盘/应用不放入双卡栏。
- 拒绝实例：traffic与紧凑system交换，traffic无法使用紧凑摘要；connection移入152px应用行空槽高度不足；不存在的行/槽；添加已存在模块；交换反向卡片高度不足。拒绝保持原草稿并显示原因。

## 输入路径和固定任务

鼠标：卡片手柄→拖到中心/空槽/行间→预览结果→放下；点击：移动→点目标，跨屏用目标列表；键盘：Tab到移动→Enter→Tab到命名目标→Enter，Escape取消；手机采用同一点击路径与底部面板，触摸拖动仅手柄支持，内容区正常滚动。

固定任务：network pair中traffic/connection交换；network改triple，system移入第三空槽；system移到network之前独占行；storage整行移到network之前。每项三种输入结果相同且一步撤销恢复。非法/取消场景对照前后快照及历史长度。

宽度往返：默认顺序traffic→connection→applications→devices→system→storage→sharing；左大右上下traffic→connection→system→applications→devices→storage→sharing；镜像connection→system→traffic→applications→devices→storage→sharing；services末尾docker→downloads→remote。宽→390→宽重复3次，logical row ID/column index/slot index与比例不变。可视拆行不成为配置源。

现有可复用：orderedLayout五模板/渲染、共享数据协调器、设备呈现、比例Pointer Events、草稿/历史。待替换：顶部大表单、HTML鼠标交换；待新增：统一意图、空槽/行间落点、跨屏目标、手势取消、就地轻工具。

自检：动作、五模板、四种输入、三个移动意图及反向拒绝、三次往返的预期均已列明，无需新增产品语义决策。M66.13通过；后续以实际代码/浏览器验证这些规则，不提前判功能通过。
