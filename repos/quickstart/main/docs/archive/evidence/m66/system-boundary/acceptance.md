# 系统菜单与 Quickstart 内容边界复验

2026-10-14。用户明确限定系统左侧菜单不改，只设计右侧 Quickstart 内容。本轮属于 M66 设计范围纠正，未确认最终视觉方案，也未开展正式首页开发或路由器安装验收。

任务树与标准见 [当前设计基线](../../../product/quickstart-home-canvas.md)。实现仅位于设计入口：宿主占位与右侧内容独立；A/B 页面工具在内容区右边；固定操作台、评审条、编辑器、配置面板及设备详情遮罩遵守内容边界。没有读取或修改真实系统菜单项、系统菜单样式、ACL、路由或折叠逻辑。

截图未包含实际系统菜单，因此桌面200px只是明确标注的空间占位，不宣称还原了菜单或其实际宽度。手机不显示占位，正式集成须沿用宿主自己的菜单行为和可用宽度。占位外壳仅供设计预览，不进入正式入口。

当前版本验证：

- SSD 包装入口下 `npm --prefix web run tsc` 通过。
- 5180 预览由本仓库生命周期脚本重新构建并启动，输出在 SSD 项目 work/vue-preview，正式 web/dist 未因本轮原型构建覆盖。
- `system-boundary-review.cjs` 访问实际公开入口 `http://192.168.9.19:5180`，通过 A/B/C × 桌面1440/平板1024/手机390 × 浅色/深色共18组合。每组检查内容边界、横向溢出、原图可见尺寸、设备行数、编辑器和可用配置入口；适用组合检查操作台滚动后固定位置、配置面板与遮罩。
- 额外检查真实设备详情深链及返回、首页工具导航、128台设备场景、320px英文布局。占位DOM和底色在编辑、主题和导航中不变。浏览器 pageerror、console error、外部网络请求均为0。
- 本次实现首轮边界自检通过，未使用历史结果替代。当前报告为 [report.json](../../../../evidence/m66/system-boundary/report.json)，截图均为本次浏览器运行输出。人工查看了 A 桌面浅色、B 平板深色、C 配置面板和设备详情边界截图。

边界验证通过不代表整体美感通过。完整设备页沿用现有正式组件，其深色详情的文字/背景对比仍需另行视觉处理；本轮只验证它未遮挡系统菜单，不改写此前视觉失败记录。
