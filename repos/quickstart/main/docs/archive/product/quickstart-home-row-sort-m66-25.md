# M66.25 总览整行直接排序

2026-10-15。基线`dbe77a9`，用户已认可整体槽位交互，明确要求补齐整行拖动排序，替换整行的指定目标列表，并授权实现、自检，失败后最多优化3次。

## 目标

总览中从行标题抓起整行，邻行让位，松手完成排序；第五行可以一次拖到第一行。只改变行的顺序，不改变行ID、内部模块、模板、比例或高度。不修改系统菜单、正式首页或原NetworkFlow组件。

## 任务树

1. 规范与边界：整行排序从模块移动中分离；明确预览、提交、取消、撤销与跨屏滚动。
2. 排序手势：左侧行标题手柄、纵向浮起、同高占位、邻行让位、稳定ID、松手提交。
3. 跨屏与输入：有界自动滚动，指针／触摸中断清理，键盘及行内上移／下移／置顶／置底。
4. 整合：删除整行的目标列表入口与行设置中的重复排序按钮，保留模块槽位交互，共用草稿和撤销。
5. 验收与交付：当前候选类型检查、真实浏览器事件、视觉检查、已有槽位回归、资源边界及公开资源校验；回填规范和证据。

## 可测试验收

- RS01：三列服务示例第五行真实拖到第一位，前四行顺序保持；反向拖回末尾也成功。行对象除序号顺序外逐项相同。
- RS02：拖动中草稿、已应用布局、历史不变；来源整行浮起、目标占位与邻行让位可见，松手只产生一步历史；一次撤销精确还原。原位松手不增加历史。
- RS03：只点行标题不进入旧移动模式，不出现整行目标列表／行间指定目标；行内菜单及Alt+上下／Home／End给出与拖动一致的结果，焦点随原行恢复。
- RS04：在不同高度的左右堆叠与普通行之间排序，不裁切或改变内部内容；视图往返保留草稿，取消编辑恢复已应用布局。
- RS05：390px跨屏从最后拖到最前、反向到最后，无手动点目标；自动滚动只在有效拖动和右侧内容范围触发，速度有界，松手／取消后停止。
- RS06：Escape、pointercancel、失焦、resize、视图切换、打开面板、卸载均取消未提交排序，清理指针监听和唯一动画帧。未超过阈值、外部落点及草稿变化不提交。
- RS07：320／390px触摸手柄可排序，正文仍正常滑动；主要操作≥44px；键盘和减少动态效果可用，系统菜单边界不变。
- RS08：已有槽位、替换、结构、空位整理及模块拖动回归；连续20次整行排序／撤销不倍增读取，历史≤30。当前受测源码与公开5180资源一致。
