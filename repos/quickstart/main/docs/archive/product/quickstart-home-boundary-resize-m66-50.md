# M66.50 · 首页边界调整

授权：2026-10-17，用户认可统一边界方案，要求实施、自检，未通过最多优化三次。

目标：默认按内容自动布局；编辑选中行时，左右分隔线调列宽、上下分隔线分配当前行内空间、行底边增加空间。保留业务、形态和完整内容，提供一次撤销与恢复自动。

## 任务树与验收标准

| 任务 | 可测试验收标准 |
|---|---|
| 50.1 规则与模型 | 明确默认自动、最小内容边界、行总高稳定、显式偏好与派生尺寸分离；旧文档默认不启用手动尺寸，非法尺寸拒绝 |
| 50.2 边界操作 | 选中行显示三类手柄；上下拖动不增加整行高度；拉高行后可重新分配；图表真实绘图区同步伸展；最小边界有就地提示 |
| 50.3 一致性 | 鼠标、触摸、键盘可用，命中区域至少44px；一次手势一次历史；无变化不写历史；Escape、失焦、缩屏中断恢复；取消精确恢复 |
| 50.4 自动与结构 | 单一恢复自动动作同时清除行高与上下分配偏好；镜像和整行排序保留对应偏好；结构重建清除失效的列分配；移动/替换不改形态 |
| 50.5 响应式与资源 | 实际拆成单卡后隐藏尺寸手柄并忽略宽屏尺寸偏好，变宽恢复；内容增长优先，不裁切、不新增卡内滚动；无新增轮询或业务实例，卸载清理测量与手势 |
| 50.6 交付 | 当前构建运行在5180；自动化、设计审图、源码保护及资源检查有当前候选证据；人工体验待用户确认，不声称实机业务验收 |

实施顺序：50.1 → 50.2～4 → 50.5 → 50.6。先完成初始实现自检；失败后最多优化三次，各次保留失败和修复证据。只改隔离原型，不修改正式首页、系统菜单、后端或设备。

证据位置：`docs/archive/evidence/m66/boundary-resize/`。当前状态：50.1～50.6技术自检全部通过，优化2轮，未使用优化3；用户随后确认首页自定义布局完成并要求提交。[验收与逐项证据](../evidence/m66/boundary-resize/acceptance.md) · [原人工任务卡](../evidence/m66/boundary-resize/handoff/review-guide.md)。193组场景、64个业务源码保护及4组交付检查通过；类型检查与差异空白检查通过。只更新隔离原型，不涉及正式发布。
