# 首页配置提示关闭：任务与验收

目标：定位 `.1` 上两条首页配置提示的实际原因，允许用户手动关闭，同时保留真实错误、默认展示和保存保护。

任务树：

1. 真实短期登录态复现提示及无法关闭，记录 API 状态和设备版本。
2. 精确区分接口不存在与暂时网络失败；为两个配置域各自增加可访问的关闭按钮。
3. 关闭只影响当前页面消息展示，不清空错误、不写配置、不启用保存；主动重读产生新提示，整页刷新重新核验，普通控件刷新不使提示复活。
4. 类型检查、相关配置回归、生产构建；候选预演和实际 `.1` 前端更新后检查，保留最多三轮失败证据。

验收：桌面/手机、中英/深浅主题可点击/键盘关闭；两个域独立；原有重新读取/恢复动作保留；错误关闭后保存依然禁用；刷新能重新提示；无横向溢出/脚本异常/业务写请求。设备服务、配置、路由、软件包不变，只更新前端与资源版本键。

证据位于本目录。`baseline` 为旧安装复现；后续候选与实际安装检查另建目录，不覆盖历史证据。
