# 结构与形态解耦开发交接

产品目标统一采用[规范1.4 R31～R36](../../../../product/quickstart-home-layout-interaction-spec.md)。当前为5180隔离Vue原型；原业务基线、数据、权限和入口继续引用[六组件](../../../../product/quickstart-home-business-widgets-alignment.md)及[网络业务](../../../../product/quickstart-home-network-widget-business-alignment.md)。

- **形态能力**：`widgetPresentation.ts`的`formCapability`声明形态是否可堆叠、可伸展及有限内容；`automaticForm`按模块与推荐版本解析；显式偏好优先。连接standard/summary可进入上下位置，接口和其他原摘要模块目前仅summary可用。没有全量放开所有完整形态。
- **版本兼容**：布局schemaVersion 3，`WidgetPreference.ruleVersion`为0/1/2：0保留旧rows/v1系统普通auto完整，1保留v2系统窄槽auto紧凑，2为新混合规则。`homeDocument.ts`迁移保留auto和旧资料，不把自动改成显式摘要；未知版本拒绝保留输入。采用新设置／恢复推荐明确进入一次事务，撤销恢复偏好和位置，修订号继续前进防止过期计划重放。
- **同一计划**：添加／迁移／替换／结构／属性／完成整理使用相同解析和计划。原位置留空、目标隐藏、唯一性、保守空位整理与业务inert保持。结构面板列明形态变化并直接提交该计划，不再追加第二次适配弹窗。
- **同一渲染**：`OrderedHome.vue`不再按上下角色旁路渲染CompactPreviewCard，统一把位置角色及偏好交给LayoutPreviewCard。旧CompactPreviewCard保留给历史比较入口；旧模块能力布尔字段只作兼容，不作为新形态判定来源。
- **高度**：真实上下列按各自内容和形态伸展能力分配；完整连接可承担剩余空间，紧凑端口保持合适内容高度。图表普通布局320px／手机300px基线；新混合或旧组主动采用新形态时，实际绘图区随组合伸展。测量结果不回写布局，不决定信息容量或形态，原NetworkFlow和采样未改。
- **紧凑端口**：NetworkInterfaceCard保留同一数据／状态／详情／分页／配置入口；新summary显示最多2个具名端口，旧推荐保留计数摘要。有限端口不代表全量不存在，标题完整清单仍有界分页。
- **总览**：与真实页面共用草稿／历史，但使用独立104px／216px缩略轨道和标题、形态、44px操作分区。缩略高度不参与真实适配，不创建新读者；形态标签表示当前响应式实际呈现，明确设置保持，auto可变化。

192组当前检查、原业务64文件哈希保护、设计者审图见[48验收](../48-review/acceptance.md)。资源检查覆盖完整服务和混合组合20次切换，后台停止适用读取，实际卸载清理计时器、观察器、监听、浮层与滚动锁；日志≤120、历史≤30。

设计构建仍通过`vite.design.config.ts`注入菜单／投影、共享读桥和隔离原向导，正式Vite配置没有这些注入。正式实现应采用显式组件与数据契约，而不是复制源码字符串替换或历史原型样式覆盖。真实存储作用域、服务端版本检查、设备接口、路由器权限及安装包一致性需在正式业务阶段独立验证。旧布局兼容在本轮以模型和合成示例证明，未宣称已迁移真实用户存储。

原系统零值口径、翻译不完整和外部DDNSTO合成回调沿用既有边界，不因布局通过而改称业务缺陷已修复。没有提交／推送／发布、没有操作真实路由器；24小时观察仍延期。本轮人工体验待用户确认。
