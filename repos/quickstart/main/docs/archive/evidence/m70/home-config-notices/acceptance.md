## 原因与复现

上一次在 `.1` 只更新前端，实际后端仍为 `0.14.0 b60f6e53...`。真实 root 登录态下，`home/v1/layout/`、`home/v1/launcher/` 均返回 404，旧错误映射统一落到“暂时无法读取”。正式首页状态条只有重读/恢复，没有关闭入口。

## 实现

- 两个配置域各有44×44px关闭按钮、独立可访问名称；移动端动作折行，支持点击和键盘 Enter。
- 关闭只修改当前页面的消息显隐，不清空配置错误、草稿或后端状态，不启用保存，不写本地缓存。
- 主动重读和配置状态变化产生新消息；整页刷新重新读取；普通控件更新不会恢复关闭的提示。重读一个域不会重新打开另一个域已关闭的消息。
- 配置 GET 404 独立归类为 unsupported，明确说明后端不支持、临时默认和无法保存。503仍为暂时不可用；POST失败仍保持 GET 结果确认，不因404跳过确认或重放写入。
- 原重新读取、备份恢复、损坏文件恢复动作保留。
