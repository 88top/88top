# M66.24 人工体验任务卡

本轮原型公开入口：[首页](http://192.168.9.19:5180/?layout=ordered) · [应用半宽示例](http://192.168.9.19:5180/?layout=ordered&preset=half)。请刷新旧标签页，新候选为构建后预览，不自动替换已打开的JavaScript。

原型复用Quickstart Vue及原曲线；系统左侧菜单不参与编辑。以下动作只影响本次预览内存，刷新恢复示例，不保存到路由器或账号。

## 主要路径

“自定义首页”进入真实页面编辑。每行“布局”选择结构，已有模块可替换或移除，空位可添加。选择器标明已有模块来源；选中后在底部预览影响，再确认放置。已有模块会移过来，旧位置留空，被替换模块仅隐藏，不交换。布局缩减时明确选择保留项。

通过分隔线或行布局中的比例／高度调整尺寸。需要快速看全结构时打开“布局总览”；点选名称再点移动，或拖名称，亦可移动整行；边缘插入只对普通单／双列扩容。总览和真实页面共用草稿及撤销。

完成时预览空位整理；复杂上下组合会要求补齐或换结构。取消整理继续编辑，取消整份编辑恢复进入时布局。隐藏不是卸载应用或删除业务设置。

## 请先独立尝试的五个任务

这些任务用于记录是否能自行发现操作，不把阅读上面的操作说明后完成视为“完全无需引导”。评审者可先只展示任务文字，再根据需要提供说明并记录提示。

1. 让应用与设备在同一行并排，调整到你认为协调的比例；不要求固定答案。
2. 把首页已有的系统状态放到指定的已占槽位，判断原槽位和被替换模块会发生什么，再确认并撤销。
3. 将三列改成两列，选择保留模块；取消一次，再真正采用一次。
4. 用整页总览将存储相关整行移到前面，再回到真实页面观察。
5. 留下一个空位，尝试完成，检查整理前后是否符合预期；返回继续编辑，再取消整份修改。
