# 局域网设备页：与首页保持视觉一致

2026-10-21。依据用户当前截图、正式设备页源码及[首页视觉基线](quickstart-home-widget-visual-standard.md)；设备业务语义仍由[产品与领域基线](../lan-device-management-product-architecture.md)定义。

## 本次已明确的改动

用户要求去掉内容顶部重复的“局域网设备管理”和“认识每台设备，并用简单的方式安排它如何连接和上网。”两行。
删除整段介绍及无用样式，页签直接衔接内容顶部。面包屑、主区域可访问名称、三项页签和各业务区域保留。
这两行已在上一轮删除，设备验收见[任务与证据](../evidence/m70/device-page-heading/status.md)。

## 本轮已认可的视觉方案

用户已认可以下方案并要求实施、自检，最多三个产品候选。[目标、任务树与当前证据](../evidence/m70/device-visual-refinement/status.md)记录本轮状态；本节为产品依据，历史截图与结果不代替当前验收。

现已完成并部署B前端599bfa8；第三候选通过32组真实登录态及六种补充状态检查，详见[当前验收](../evidence/m70/device-visual-refinement/acceptance.md)。下表保留实施前的问题及对应已认可调整，分组/设置内部业务表单不在本轮重画范围。

原则沿用首页的“淡雅底面＋业务点彩”，不把管理表格改造成另一套展示型首页。

| 区域 | 实施前问题 | 已认可调整 |
| --- | --- | --- |
| 页签与正文外壳 | 宽灰条和白色内容视觉割裂，重复标题又增加一层 | 保留一套轻量页签，白色内容用首页相同的细边框和10px圆角；延续当前原生左右20px/手机16px外间距，不恢复居中限宽 |
| 设备工具区 | 设备标题/说明、在线筛选、更多筛选分散在多个垂直层级，左侧空白多 | 桌面把在线/全部/已设置与搜索、排序、刷新、添加组织成紧凑工具区；更多筛选作为同一工具区展开项。手机按搜索、状态与操作顺序自然换行，触控目标至少44px |
| 字体与颜色 | 紫色主操作与首页蓝色不一致，名称、地址、说明多用接近的灰色 | 16px区域标题、14px正文、12px辅助说明；主文字加深，次要说明用明确语义色而非叠加opacity。操作蓝跟随首页主题令牌，业务图标保留有意义的品牌色 |
| 设备与地址 | 多个未命名设备不易扫读，宽屏地址列占据大量空间 | 名称和当前IP视觉相邻，IP保留等宽读数；品牌/类型作为辅助信息，未知不伪造。地址列有合理弹性上限，IPv6保持可读和完整可达，不用空白填满整表 |
| 状态与流量 | 在线只有小点带绿，其他值都较平；大面积隔行底色偏重 | 在线文字与小点同为语义绿，离线/未知保留各自文字；上下行沿用首页对应配色和箭头，未知采样仍显示未知。白底细分隔线＋轻悬停，减少隔行大色块 |
| 操作 | 每行详情描边较抢眼，添加设备紫色浓底与整体不协调 | 详情采用首页同类轻描边动作，整行仍可打开抽屉；添加设备为工具区唯一主要动作。保留焦点和键盘入口，不靠颜色区分权限 |

推荐实施顺序：顶部和外壳 → 工具/筛选区 → 表格字阶/列宽/业务点彩 → 手机和深浅主题。
不新增统计卡，不因界面精简删除地址来源、在线语义、权限、策略或降级说明；完整资料与真实表单仍进入现有详情抽屉。

后续用户已认可并完成[局域网设置的信息层级与局部刷新](lan-settings-interaction-refinement.md)。该阶段允许设置组件按方案修改，替代本阶段“设置内部表单不重画”的范围限制；不改变设备身份、权限和事务基线。

验收使用同一批真实设备对比首页与管理页，检查中英/深浅/320～2560px、长IPv6、空/加载/错误、筛选/排序、抽屉和焦点恢复。实施状态及当前版本结果以本轮证据为准。

实现边界：桌面名称列最多320px、当前地址列最多230px，地址排在名称之后，IPv6允许换行；剩余宽度留给策略与操作，不恢复居中限宽。设备内容宽度≤980px采用现有手机资料卡，工具与状态筛选自然分行；320px更多筛选单独一行，避免英文挤压。手机页签省去装饰图标以保留文字空间。浅色使用首页蓝#155dfc、绿#008236、上行#7534d7、下行#0876bd；深色分别#91b9ff/#70e2b2/#c7a0ff/#68d6ff，显式主题优先。只有ready速率着色，采集中/缺失/延迟保留既有文本与降级提示，不冒充实时就绪。
