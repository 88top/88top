# 局域网设置：状态优先、配置按需

2026-10-22 用户认可的组件准备交互由[M71功能组件契约](lan-feature-components.md)补充：统一抽屉、独立组件状态、安装/启用/切换分别确认。原页面内安装按钮与安装后全页load的实现由该契约替代；本文件关于局部降级、草稿保留、现有业务事务和服务重新检查的规则继续有效。

2026-10-21，用户已认可并要求实施。延续[设备页视觉](lan-device-visual-refinement.md)与[业务架构](../lan-device-management-product-architecture.md)，本文件只补充局域网设置的呈现和局部检查交互，业务事务/权限仍以上述架构为准。[任务树与证据](../evidence/m70/lan-settings-refinement/status.md)。

当前已部署B前端9f31d4f，第三候选通过24组已登录页面与12组补充交互验证，[当前验收](../evidence/m70/lan-settings-refinement/acceptance.md)。B现有地址配置读取的静态字段兼容错误独立记录，尚未修复；摘要只在成功读取时显示。

1. 选中局域网设置后，不再重复一组标题与介绍；保留可访问区域名称、网络服务/上网路线/规则台账。
2. 地址分配观察、DHCP编辑权、路线编辑权是不同信息，分别据现有接口判断。不再使用“本页只读”泛指限速/安装等独立能力。没有可靠的管理地址时不伪造“前往主路由”链接。
3. 无DHCP编辑权时默认展示本机配置摘要：本机配置开启/关闭、地址池、租期；完整字段（含默认路线）通过“查看本机配置”展开且禁用，不显示禁用的预览按钮。摘要注明不是上级路由器当前生效配置；未知/无效响应显示读取失败或未知，不能展示前端默认值作为真值。有编辑权时保留原完整表单与Plan/Apply事务。
4. 限速异常在当前卡片说明原因，重新检查就近放置；“查看执行方式”直接展开高级区域并聚焦原执行方式控件，不自动切换、安装、启动或保存。原迁移与恢复入口完整保留。
5. 重新检查只更新服务观察结果，保持DHCP、限速、路线草稿与待确认计划、页签和展开状态。检查失败明确显示未更新；超时可重试，并丢弃迟到或卸载后的结果。无新增轮询。沿用既有globalConfigs组合只读接口，后端仍读取其原有组合数据源；前端只采用其中限速观察，不再调用其他设置接口或回填其他草稿，不另造有锁的软件中心/配置写接口。
6. 白/深色底面、细边框；蓝操作、绿正常、橙异常。两卡顶部对齐、自然高度；手机一列，说明不重复堆叠，关键动作44px。所有状态同时有文字，不靠颜色表达权限。

实施分轮记录，以当前候选证据为准；旧设备页源码不变的保护条件在本阶段明确替换为：设置组件允许本方案中的模板/刷新适配改动，原写事务函数、设备列表/分组/详情等业务边界继续保护。
