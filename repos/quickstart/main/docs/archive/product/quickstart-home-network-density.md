# 网络连接与网络接口：紧凑排版

范围：隔离Vue首页原型。用户已认可完整信息、紧凑排版方案；不改正式业务源码、状态来源、布局文档结构或已保存的用户空间分配。

## 目标及任务树

1. 核验基线：记录当前工作区、公开预览和两个控件的截图/尺寸；保护原业务与设计业务脚本。
2. 网络连接：IPv4/IPv6/DNS改为横向信息行；地址显隐使用有无障碍名称的眼睛按钮，协议和DNS来源用辅助文字；保留状态、秒级时长和修复动作。
3. 网络接口：当前紧凑端口形态改为两层信息；名称/状态在上，逻辑接口/速率在下，整块仍可进入原详情。完整形态保留原总数、端口和详情。
4. 高度契约：校准当前连接标准形态与当前接口紧凑形态的内容下限；沿用自然测量和拖动约束，旧布局尺寸、用户手动空间及旧版摘要兼容语义保留。
5. 当前候选验收：尺寸、截图、长值/异常/无地址/多数据、深浅主题、中英、隐私、原表单、详情、导航、布局拖动/撤销/取消。

## 可测试验收标准

- 在与用户截图相近的桌面卡宽下，正常网络连接目标220～240px，紧凑网络接口目标135～145px；不是固定高度，异常、触屏、窄宽、长值可自然增高。
- 标题、正文、辅助文字沿用现有字阶；不以缩小字体、隐藏字段或内部滚动实现降高。
- IPv4/IPv6仍独立默认隐藏，支持各自60秒显隐，关闭详情/切换形态恢复隐藏；无地址明确显示“暂无地址”，不能误判联网能力。
- 状态、协议、当前接口、DNS来源与原有DNS数量上限/完整详情保持；所有异常和原DNS/软件源修复动作保留。
- 端口状态与互联网状态独立；两个预览端口及完整分页、字段、点击/键盘详情、焦点恢复保持。
- 默认五行、形态偏好、左右比例、上下拖动、行空间、撤销/取消/应用语义保持；自然尺寸只作为派生值，不写入用户布局。
- Playwright当前候选无脚本错误/外部业务请求/页面横向溢出；实际打开前后截图进行视觉检查。

证据目录：`docs/archive/evidence/m66/network-density/`。首轮实现后自检，未达标最多优化三轮；每轮明确问题、修正与当前候选结果，三轮仍不通过则停止并说明。历史验收不代替当前候选。
