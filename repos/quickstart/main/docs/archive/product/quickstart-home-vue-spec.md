## 推荐的产品决定

1. 原模块顺序保留，在网络区下方、配置工具上方插入一张设备摘要卡。
2. 桌面/平板最多6台、手机最多3台；摘要始终有界。总数量来自完整库存，不由摘要行数推算。
3. 名称优先，品牌以文字保留，图标使用项目原创类别图标；手动图标优先，未知类型采用电脑形态。
4. 默认展示在线状态、品牌/类型、当前地址和接入方式；速率默认收起。路线、限速、时段、额度进入详情。
5. 显示“在线 N / 本次开机发现 M”，限定本机可观察范围；未知数量不写0，未知速率不写0 B/s。
6. “查看全部”进入完整列表的全部筛选；单设备以稳定deviceId打开其详情概览。
7. 设备摘要可在模块设置中独立隐藏，既有模块隐藏偏好保留；正式实现不能只把偏好存到localStorage。

以上位置、6/3台密度和默认字段仍是待确认候选，不以用户认可 Vue 复用方式代替具体设计确认。
当前原型通过原模块设置演示既有模块的内存偏好；设备摘要的正式服务器偏好键留给M69。

## 身份、权限和降级

- 首页与完整页复用同一库存身份、分类、图标偏好与呈现函数。中文设备备注与ASCII DHCP主机名分开。
- 当前地址和历史地址分开；摘要无当前地址时明确说明，不能把历史地址写成当前地址。
- 在线状态与联网权限独立；示例平板在线但允许在使用管理中呈现暂停联网。
- 只有所选LAN的本机DHCP分配权及相关健康允许路线编辑；“旁路由”仅解释拓扑，不决定写权限。
- 外部分配时提示到实际分配地址的主路由设置；分配方不明确时只读。DNS继续跟随路线。
- 浮动网关未启用的示例目标不可选择；浮动IP持有与DHCP职责不混同。
- 统计能力五态只影响对应统计/限速区域；设备清单、资料与独立联网权限不依赖引擎。
- 过期快照显示时间与待确认状态，重试成功后恢复。首次失败、旧API、权限拒绝分别给出原因。
- 设备深链消失时不按旧IP寻找替代设备；保留列表并提示原因。

## M69 任务树与验收标准

| 任务 | 实施内容 | 可验证结果 |
| --- | --- | --- |
| 读取共享 | 将首页和设备页接入共同库存/上下文/规则/遥测读取接口；身份按deviceId归并 | 名称、数量、状态、图标和权限在两处一致；没有首页旧接口的另一套设备口径 |
| 摘要组件 | 按确认位置、密度和字段迁入正式组件；独立服务器模块偏好 | 用户隐藏/恢复后刷新仍保持；旧模块偏好不丢失；128台不展开完整首页列表 |
| 正式导航 | 查询参数驱动正式设备页的选择和筛选，补齐详情关闭/后退/刷新 | 单设备始终同身份；设备消失有解释；未保存输入和用户上下文不因自动刷新丢失 |
| 读取边界 | 库存30秒、上下文60秒、速率按需5秒；并发合并、超时、失败退避；隐藏/卸载停采 | 每类请求最多一个在途；没有N+1详情查询；失败不会密集重试；往返导航不叠加后台轮询 |
| 缓存边界 | 每类保留最新快照，按后端容量上限接收；趋势最多60点；历史仅按需 | 长时间刷新不累计快照数组；LAN/版本改变不会复用错误缓存；不新增无界统计后台 |
| 兼容与错误 | 结合接口能力/服务器版本和真实响应解释404；独立处理401/403/-1001 | 旧后端提示兼容安装；权限拒绝不误报离线；HTTP200仍检查业务result |
| 当前验收 | 先核对本轮候选与安装身份，再检查B/C实际API和登录态UI | 三端、主题、语言、关键请求、导航与降级有当前证据；不沿用历史全绿 |

API映射继续使用既有 `devices/`、`network-rules/`、`device-traffic/`、`router-context/`、`system/module-settings/`。
多LAN语义必须由实际服务契约支持；不能仅加前端缓存键就宣称支持选择任意LAN。
设计原型目前没有实现真实API的10秒超时、120秒退避与完整共享store，这些是M69验收项，不拿示例测试代替实机资源验证。

### 最终视觉问题与停止点

手机深色截图中原QuickActions标题仍为#333；深色卡片下难以阅读。
证据：`docs/archive/evidence/m66/vue/05-review/mobile-dark-viewport.png` 与 `visual-limitations.json`。
这是自动化布局/加载检查没有覆盖的真实视觉失败，已更正提前的通过判断。
三次优化已用完，不继续第四次修改。下一轮建议在原组件将硬编码移动标题/副标题颜色改为现有主题变量，
补充实际计算颜色及截图检查后重新验收；不以仅覆盖预览CSS掩盖原组件问题。
原系统信息的圆环区在手机端允许内部横向滚动，此项与页面级横向溢出分别记录。
英文复核还发现原词典缺少“网络流量”“网络连接和IP地址”“日志查看”“系统维护”等条目，界面会回退中文。
这同样记录为遗留质量问题，不能将英文组合的“加载成功”说成翻译完整通过。
