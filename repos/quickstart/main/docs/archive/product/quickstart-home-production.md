## 配置与事务

- 布局域保存 schemaVersion=3、rows、widgetPreferences；不保存本地 revision、测量结果、实时地址、权限快照或组件代码。保留 height/split 仅供既有兼容；minHeight/upperShare 是用户意图。
- 启动台域保存 schemaVersion=1、固定 ID 顺序和自定义链接。最多24固定、64链接；48分页属于呈现规则。新应用不自动固定；取消固定保留实体；删除链接和引用在同一域原子提交；恢复默认固定不动链接库。
- 控件定义、默认模板版本、推荐规则版本随代码发布；服务端版本独立于结构版本和本地草稿 revision。
- 选择两个独立原子 JSON 文件：`/etc/quickstart/home-layout.json`、`home-launcher.json`，各自有效备份 `.bak`。没有跨域原子事务需求，不为节省一个文件扩大故障范围。恢复布局不会覆盖启动台。
- 文件封装包含随机 generation、单调 revision 和内容。并发令牌包含 generation，恢复出厂/重建配置后旧缓存或旧标签不能覆写新配置。所有更新必须带读到的版本；冲突保留草稿，显式重新加载，不自动覆盖或合并。
- 保存流程：限制请求大小→严格解码/结构验证→锁定并读当前文件→版本检查→无变化直接返回→同步有效旧备份→临时文件0600写入/fsync→rename→父目录fsync。错误响应不记录链接内容。提交后同步失败属于结果未知，客户端读回确认，不能直接重复写。
- 本域主备文件都不存在时，首次认证GET在完整读取旧设置后原子初始化并保留迁移来源；后续GET不写。真实空布局/零固定必须保留。浏览器缓存永不自动上传。不能把旧设置读取失败当作默认；迁移只执行一次，不双写旧键。
- 配置空文件、截断、超限或结构无效：尝试有效备份用于展示并标明恢复状态；禁止普通保存覆盖损坏原件。显式恢复需先保留损坏证据。未来版本：只读保留，旧代码禁止降级覆盖。读取失败临时展示默认值和错误，不写文件。
- 首版结构有界：32行、每行1～3列、每列1～2槽且仅五种合法模板、11控件全页唯一、行ID有界且唯一、权重和比例有限、空间意图不超过既有1600px范围。禁止未知字段/控件/形态；未来版本整体只读，不能忽略未知字段再保存。
- 链接只接受有主机的 HTTP(S)，名称/URL/图标/ID有界，拒绝控制字符、凭据字段和可执行协议；不在服务器探测URL、不抓远程图标。正文以文本绑定，外开链接使用 noopener/noreferrer。

首帧呈现内置默认布局与各卡加载状态，不先隐藏全部。配置、能力及控件读取并行，但配置失败不阻塞整个页面。后台更新快照不重建整页或覆盖正在编辑的草稿。已确认缓存只存配置，不存凭据、实时设备或地址显隐；只有可信路由器/作用域/generation上下文匹配才使用，本地存储不可用仍工作。身份尚未可信前用内置默认，不猜测同IP就是同一设备。

临时默认展示与主动恢复默认并保存是两个动作。恢复默认通过现有草稿/预览/撤销，不增加数字表单；未来版本和不可读配置不能通过普通恢复默认静默覆盖。备份恢复、升级保留、系统备份/导入和降级只读策略须由包链路一起验证。

## 控件开发方式

采用已有代码的清晰分工，不建任意插件平台。

| Module | Interface 与责任 | 禁止承担 |
|---|---|---|
| 布局与形态 | 稳定ID、五模板、纯规划/校验、草稿历史、派生排布 | HTTP、持久化、业务状态、后端DOM计算 |
| 持久化 | read/save及明确错误；版本、原子文件、恢复策略隐藏在实现内 | Vue组件名、HTML/CSS、实时数据 |
| 共用外壳 | 标题/图标/主要操作/菜单/正文/提示槽，主题/焦点/字阶 | 判断磁盘健康、联网状态、DHCP权限 |
| 业务 Adapter | 原数据来源、能力/权限、原动作/表单、失效刷新 | 擅自删字段/动作，显示形态充当独立身份 |
| 页面读取 | 每通道唯一owner，去重、最后快照及错误、可见订阅/卸载清理 | 第二套全局getData与逐卡轮询叠加 |

Seam 位于布局渲染控件及业务填入外壳的位置。正式实现抽取可复用的布局纯逻辑和编辑器，去掉 URL 场景、合成请求、演示导航、原型宿主与内存会话。设计原型继续引用共享逻辑作对照。六个原业务卡改成显式模板/槽位，保留原处理函数和表单；不得把设计编译变换、DOM扫描或请求猴补丁作为生产接口。

设备卡复用完整管理的 deviceId、resolveDeviceVisual、名称/品牌/图标、在线和当前/历史地址语义、能力上下文，真实深链以 deviceId 定位。缺 netpolicy 局部降级，不让清单不可用。路线写权限由所选LAN DHCP分配权决定，首页不新建策略事务或无界统计。

按用户最新设备卡反馈，首页每条设备使用原有两行：名称＋地址，第二行替代重复的“类型待确认”，不增加第三行或行高。当前IPv4优先、其次当前IPv6；没有当前地址才显示明确标注的历史地址，再无地址用MAC/稳定ID辅助识别。禁止直接使用可能回退到历史地址的primaryAddress冒充当前IP。长IPv6紧凑显示首尾，完整值放入提示和无障碍名称；品牌/类型保留在提示，原deviceId导航、状态/权限/图标语义不变。实现及当前设备证据见[设备地址紧凑识别](../evidence/m70/device-address/status.md)。

读取所有权以逐项源码盘点为准：状态/系统5秒、端口10秒及远程3秒等原节奏先登记；隐藏模块停止适用消费、后台暂停、卸载取消在途回调/计时器/观察器及dispose图表。不增加频率，连续20次切换检查owner和实例回到基线。性能先记录JS/语言/路由/图表/模板开销再定预算，不预称秒开。

首版不启用浏览器持久缓存：当前已有LuCI上下文尚不足以在读取服务端前可靠识别换机/恢复出厂，不能把同IP副本当可信配置或自动上传。2026-10-19用户反馈默认内容/文字闪现后，首次呈现规则更新为：仅等待layout/launcher两份有界首页设置，保留顶部并显示中性内容占位，800ms后才显示轻量加载文字；容器宽度就绪后直接呈现保存的布局/固定项。正常读取不插入临时状态条，不先绘制默认控件或空首页。业务/软件中心仍独立并行读取，不用全页业务Promise.all阻塞。真实配置错误继续按原权限、只读、恢复与明确临时默认兜底处理，合法空首页保留；初始就绪锁存，手动重读不再次覆盖整页。该规则覆盖此前“先显示内置默认加载状态”的呈现建议，不改变配置存储和恢复契约。当前B17411e9及证据见[刷新验收](../evidence/m70/refresh-stability/acceptance.md)。后续仅在身份协议和性能测量证明收益后启用已确认缓存；本地存储不可用不影响此版，未经测量不承诺秒开。
