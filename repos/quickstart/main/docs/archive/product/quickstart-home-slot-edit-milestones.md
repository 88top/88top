## 共同交付和执行纪律

- 范围仅隔离Vue原型、5180、合成数据、内存草稿。左侧系统菜单、原NetworkFlow主视觉和设备业务语义保持。正式首页、真实API／持久化、SDK／IPK／APK和路由器部署均不纳入本轮。
- 开始每阶段时先输出该阶段任务树、验收标准和证据位置；实现后自检。初次失败后最多优化3次，保留全部失败和修订；仍失败或需要重要产品语义决定时停止并说明。
- 实施阶段依次推进；同一阶段的适配契约和消费它的UI共同验收。不得先做一套宽松演示，最终再补规则。
- 最初请求先形成规范和计划，后续用户已授权连续实施；文档自检不算M66.19原型契约通过，阶段实际结果另记。隔离原型可以重建预览，仍不启动真实设备测试。
- 每阶段证据包含当前候选、前置布局、真实输入路径、前后快照、通过／失败／未验证和优化次数；后续候选变化须重验受影响项。自动化、设计者审图、用户确认分开记录。

## M66.19 规范映射与统一适配契约

**目标：** 把产品规则变成原型中唯一、可验证的模块适配与操作契约，后续界面不各自解释添加、移动或整理。

任务树：

- 盘点十类模块及五模板 → 登记稳定ID、展示规格、实际最小宽高和上下摘要能力。
- 规范R01～R16 → 对照当前命令、状态和读取实现 → 列出保留／替换／新增清单。
- 建立统一操作输入、适配检查、变更预览及拒绝原因 → 定义草稿／已应用／历史边界。
- 将SC01～SC24转成有前置与预期布局的测试数据 → 核对规范覆盖。

可测试验收：

1. 十类模块均有适配登记，包含标准与紧凑的差异、最低尺寸、业务入口和未知空间处理；不使用模块名称或屏幕宽度替代身份／容器宽度。
2. 对五模板的每个角色做适配用例；每种开放规格验证最低宽高边界、边界以下的拒绝及展开后行为。应用紧凑网格不能误当上下摘要。
3. 添加、已有模块迁移、替换、隐藏、结构变化、完成前整理共用一套命令和校验；SC01～SC13具备明确前后快照及拒绝断言，不用空函数或仅文案模拟通过。
4. 所有R规则都有后续阶段／场景映射；不留下“交换还是替换”“空位何时整理”“缩槽多余项去哪”等未说明语义。尺寸候选值与实测值分开标记。

证据：`docs/archive/evidence/m66/slot-edit/19-contract/`，模块能力表、规则—实现差异、场景数据、契约检查及优化记录。

## M66.20 可伸缩模块与应用卡视觉基线

**目标：** 模块能以合法规格进入不同槽位；应用卡半宽时自然、美观，真实页面可用于判断效果。

任务树：

- 适配登记接入真实卡片 → 容器宽高决定规格／内容密度 → 最低空间反馈。
- 应用标题精简 → 图标名称网格自动换列 → 全部／系统工具／软件中心分工。
- 整行／半宽／窄卡示例 → 与相邻模块等高 → 主题、长名称和异常状态审图。

可测试验收：

1. 十模块在各自支持的槽位上有真实Vue内容，无CSS裁切冒充紧凑内容；不支持的槽位有明确原因。原曲线和同排外框正常，对齐误差≤1 CSS px。
2. 提供整行与半宽应用示例，半宽及窄卡按实际容器换列，不用整行／双列模板名称硬编码高度；应用0／1／6项、长中文／英文名、失败状态均无入口遮挡。
3. 常用顺序与选择保持，隐藏项可由“全部”找到；原五快捷功能、八系统工具和软件中心安装更新入口可实际到达。卡内不出现额外滚动条，清单刷新不改变外层布局和行高。
4. 320／390／768／1440px、深浅主题、中文／英文检查代表形态；记录真实容器尺寸和阈值临界点。审阅实际截图的留白、名称可读性、标题密度，不能仅以DOM未溢出代替视觉检查。

证据：`docs/archive/evidence/m66/slot-edit/20-modules/`，规格尺寸表、半宽示例、真实导航报告、视觉截图与设计自检。

## M66.21 真实页面槽位编辑主流程

**目标：** 不用拖动即可完成选结构、添加、移动已有模块、替换和移除，成为默认整理路径。

任务树：

- 行布局图示 → 空／已占槽位操作 → 带适配与来源的模块选择器。
- 新增／已有模块迁移／占位替换 → 影响预览 → 原子提交与撤销。
- 扩槽／缩槽保留项选择／镜像 → 确认与取消 → 空布局找回。

可测试验收：

1. 从正常首页进入真实页面编辑；对五模板均能选中正确逻辑槽位，空位可添加、已占位可替换或移除，不依赖目标列表或长距离拖动。
2. SC01～SC09用真实点击覆盖：目标已占且来源也已展示时，来源留空、目标为A、B隐藏；没有隐式交换，全页无重复。一步撤销恢复全部相关位置。
3. 选择器准确标明已有模块来源、移到这里及不适配原因；确认前草稿不变，选择自身／关闭选择器不增加历史，取消后焦点恢复。
4. 缩槽必须先展示保留与隐藏结果，取消无变化，不把多余模块自动塞到新行；镜像保留角色。所有动作不写已应用布局，不清除业务设置。
5. 普通态不显示编辑落点；编辑态仅展开当前对象工具，业务入口不误导航。全部隐藏时仍能添加、恢复及找回完整工具入口。

证据：`docs/archive/evidence/m66/slot-edit/21-slots/`，五模板操作报告、替换／迁移前后快照、保留项选择和撤销／取消证据。

## M66.22 完成前整理与草稿恢复闭环

**目标：** 空位在编辑中稳定，完成时整理可预测；任何冲突都不丢模块或提交半成品。

任务树：

- 空位／空行草稿呈现 → 普通行简化规则 → 上下组合保守规则。
- 完成前整页预检 → 前后结果预览 → 高度建议／问题定位 → 应用。
- 整理取消／撤销／取消整份编辑／恢复推荐 → 内存会话及刷新语义。

可测试验收：

1. SC10～SC13检查普通三→二等分、二→一、清理空行和不跨行补洞；编辑中来源空位可继续填入，不立即收缩、跳动或重排。
2. 完成前预览与提交结构、顺序、比例及规格一致；取消整理预览精确返回原草稿，取消整份编辑返回已应用布局。无变化时不多一次确认。
3. 使用合成硬性适配限制和不足行高作负例：定位问题、保持草稿和已应用布局；可补齐／换结构／移除后再完成。高度建议须主动接受；复杂堆叠不猜测转换结果。
4. 上下组合整列为空且另一列单模块可合法变单列；其余不完整组合引导修复。完整无空位行的自定义比例不被重置。
5. 一次成功动作一次撤销；完成、重新编辑、取消和恢复推荐的边界明确；进入详情再返回保持本次内存布局，刷新恢复示例。连续操作后历史≤30，隐藏模块设置不丢失。

证据：`docs/archive/evidence/m66/slot-edit/22-normalization/`，整理前后快照、硬限制／复杂结构拒绝、修复后通过及恢复矩阵。

## M66.23 次级整页总览与互斥输入

**目标：** 长页面可快速整理，同时不引入另一套布局语义或与主流程冲突。

任务树：

- 紧凑结构总览 → 稳定模块识别及定位 → 共用草稿／历史。
- 模块／整行移动 → 槽位替换及边缘插入预览 → 满列和堆叠边界。
- 指针／点击／键盘 → 移动／调宽／调高互斥 → 中断清理与焦点。

可测试验收：

1. 1440×900下，默认四逻辑行及总览主工具可在右侧首屏看全，名称和上下关系可读；总览压缩不改变真实行高。手机可有纵向滚动，不通过缩到不可点强求一屏。
2. SC14～SC17：总览与真实编辑往返三次，草稿、选中模块及历史相同；拖动预览不提交，切换取消半成品。完成／取消共同作用于同一份草稿。
3. 移动到已占槽位按R04/R05替换；边缘插入只允许普通单／双列扩成双／三列，预览等于结果。满三列、上下组合拒绝隐式扩容；整行移动只改顺序。
4. 鼠标、纯点击、键盘完成“已有模块移入空位／替换已有模块／整行排序”得到一致快照；三者共享拒绝原因，不靠调用内部函数代替真实输入。
5. 移动／调宽／调高／结构面板互斥；Escape、pointercancel、resize、失焦、目标变化及卸载恢复并清理。画布不同时铺满说明，不以另一条常驻工具条增加模式负担。

证据：`docs/archive/evidence/m66/slot-edit/23-overview/`，总览截图、输入一致性报告、视图切换和异常中断证据。

## M66.24 当前候选全流程验收与人工评审

**目标：** 交付当前5180完整候选，明确技术正确、设计审图和用户体验三类结果，形成可继续修改的产品基线。

任务树：

- 当前候选标识 → SC01～SC24及TypeScript回归 → 响应式／异常／权限。
- 实际截图与图表PNG → 读取／监听器／历史边界 → 产品任务体验。
- 已实现规则回填 → 交付操作说明、差异、未验证项 → 人工确认记录。

可测试验收：

1. 当前候选TypeScript及SC01～SC24通过，检查浏览器控制台、网络和真实输入，不能仅验证HTTP 200。所有R规则有当前证据；旧断言按新语义迁移并有说明。
2. 320／390／768／1024／1440／1920px × 深浅主题 × 中文／英文共24组普通态基准；编辑／总览／选择器／整理预览在320、768、1440px有代表组合。无非预期横向溢出、遮挡或左侧菜单侵占，主要触摸入口≥44×44 CSS px；焦点、Escape、键盘和减少动态效果偏好可用。
3. 五模板均做三次宽窄往返；加载、空、失败、旧版、缺服务、不同DHCP权限和长名称覆盖，局部降级不改布局。手机核心路径无需拖动；记录模拟或真实设备，不冒充真机／读屏器认证。
4. 连续20次移动／总览切换／尺寸调整不倍增读取；原图单一5秒采样，10600ms观察2～3次，隐藏／卸载后5600ms新增0次；日志≤120、历史≤30，无遗留手势监听器。无真实设备请求，不宣称路由器资源或24小时观察通过。
5. 24组基准保留正常视口及同宽完整内容PNG，审阅导出图中原图表区域，不能只检查活canvas。记录源码标识、公开资源哈希及实际5180访问结果，证明交付与受测候选一致；不复用旧截图冒充新候选。
6. 用户按任务卡独立尝试：①应用与设备并排；②将已有系统状态移入指定槽位并确认替换；③缩减一行并选择保留模块；④用总览移动整行；⑤完成前整理及取消。记录是否需要提示、误操作／撤销次数和主观评价，未参与不判通过；用户确认后才记为最终体验确认。
7. 交付可访问地址、规则覆盖、操作指南、已通过／失败／未验证及正式开发留项；本阶段完成标准包含人工确认，技术检查通过时可交付“待人工评审”，不得提前标记整个阶段完成。
