# 首页结构与形态解耦：M66.44～M66.49

2026-10-16。用户认可方向后已授权M66.44～49连续实施。本文保留各阶段原任务树与验收标准；当前技术实现及192组检查已完成，见[状态](../evidence/m66/structure-presentation/status.md)、[48验收](../evidence/m66/structure-presentation/48-review/acceptance.md)及[本轮人工任务卡](../evidence/m66/structure-presentation/49-handoff/review-guide.md)。人工体验待本轮用户确认。

当前代码基线为`8a12d35`加工作区中M66.38～43的未提交改动。实施前再次检查状态并保留已有改动。当前可运行实现及证据仍见[上一轮计划](quickstart-home-natural-layout-m66-38-43.md)和[状态](../evidence/m66/natural-home/status.md)，不得将其作为本轮通过证据。产品规则继续统一维护于[交互规范](quickstart-home-layout-interaction-spec.md)，本轮实施时修订为1.4；本文件不另建竞争性产品基线。

## 本轮共同目标

结构只决定位置，形态决定信息与动作，空间分配决定自然高度和伸展。右侧上下不代表必须摘要、不代表均分，也不代表上方永远完整、下方永远紧凑。用户明确选择的形态跟随模块移动；自动规则按模块声明推荐。首个必须验证的组合是网络流量＋标准网络连接（完整原连接信息）＋紧凑端口形态；不凭解除全局限制就开放所有模块的所有形态。

“左大右上下／左上下右大”的用户文案改为“左单右双／左双右单”，保留已有模板ID、模块ID与布局顺序。“完整连接信息”对应现有standard业务形态，不为文案再造一个含义重叠的full枚举。

原业务基线、字体、主操作加更多、标题详情入口、有限首页清单、共享快照、无DHCP分配权解释及局部降级继续有效。范围仍为5180隔离Vue原型；本轮不修改正式首页、系统左侧菜单、真实偏好存储、API、路由器、SDK或发布资产，24小时观察继续延期。

## M66.44｜规则、交互一致性与兼容契约

目标：消除“上下槽位等于摘要”的产品约束，先明确所有操作应有的结果。

任务树：

1. 将规范修订为1.4：结构／形态／空间职责、模板命名、首批支持矩阵、图表伸展及高度分配。
2. 建立操作决策表：添加、移动、替换、镜像、改结构、调宽、显示设置、空位整理、总览、排序、撤销、取消和响应式。
3. 定义旧rows／v1／v2的兼容策略，区分显式偏好与旧auto规则；新版本默认规则不在加载时自动改造旧页面。
4. 建立规则→任务→自动用例→视觉与人工任务的追溯表，标记被替代的1.3规则和保留的业务约束。

可测试达成标准：

- 所有上述操作均有明确输入、预期结果及确认条件；无需改变用户意图的换行／自然增高不新增确认。
- 上下对调后形态跟随模块，镜像不修改模块偏好；“右上完整、右下紧凑”仅为组合示例。
- 显式标准／紧凑保持；旧auto加载保留旧推荐含义且仍为auto，不暗中改成显式紧凑。采用新推荐通过现有显示设置／恢复推荐的预览事务完成，不新增常驻工具或升级弹窗链。
- 图表规则明确替代“任何组合始终固定320px”：普通布局保留原视觉基线，组合中允许绘图区随内容适配；不得只拉外框留下大片空白。实际高度不反向决定形态或内容数量。
- 未实测的最小宽度、图表伸展范围和支持组合标为候选；每个候选均有后续校准用例。

证据：`docs/archive/evidence/m66/structure-presentation/44-contract/`。

## M66.45｜统一形态适配模型与旧布局兼容

目标：所有变更路径共用同一套形态判断，兼容规则真正进入模型。

任务树：

1. 由模块级stacked布尔限制转为形态级适配声明：可用位置、最低宽度、有限内容、自身高度需求和伸展能力。
2. 统一解析、候选计划、影响说明、提交与过期计划检查；清除上下位置强制summary的判断。
3. 为旧auto推荐增加可版本化兼容口径，必要时升级布局文档；保留身份、顺序、列宽、形态、属性和旧兼容资料。
4. 编写有意义的契约用例，覆盖支持／不支持、迁移、往返、原子事务和边界。

可测试达成标准：

- 标准连接在右上、右下都可得到合法计划；明确紧凑接口在另一位置仍紧凑。不支持的形态有准确原因与替代路径。
- 相同文档、上下文和操作得到同一结果，选择器／拖放／改结构不分别裁决。
- 旧rows、v1、v2迁移及重复读回不丢模块、属性或显式意图，不修改输入对象；旧auto实际语义保持；未知版本拒绝并保留原输入。
- 新推荐的采用是可预览、可取消、可一次撤销的变更；过期计划不提交，拒绝／自身目标不记历史。
- 实际测得的高度不写回文档，数值采样不改变容量或偏好；不得把所有standard直接开放到所有上下位置来通过测试。

证据：`structure-presentation/45-model/`。

## M66.46｜混合形态真实渲染与网络组合视觉

目标：真正展示“完整连接＋紧凑接口”，做到主次清楚、外框整齐且没有强制均分。

任务树：

1. 移除OrderedHome按上下位置直接渲染CompactPreviewCard的旁路，实际渲染消费统一解析结果。
2. 标准网络连接保留原状态、在线时长、IPv4／IPv6隐私、DNS及来源、主操作与异常动作。
3. 实现紧凑端口形态：首页有界展示端口名称、链路状态和有数据时的协商速率；完整详情仍可达；不得只剩计数或新增横向滚动。
4. 按内容分配右侧高度，紧凑卡优先自身合适高度，剩余空间由声明可伸展的卡片承担；图表真实绘图区适配组合。
5. 校准原字体、明暗状态、列宽和可用组合范围；为首个组合建立可直接访问的示例。

可测试达成标准：

- 真实页面同时出现标准连接的全部原首页字段和紧凑接口的端口信息，两个模块保持独立身份、数据和入口。
- 上下交换及左右镜像后展示形态仍正确；上下不强制50/50，也不通过扩大字号填充空间。
- 桌面组合中左右外框底部误差≤1px，上下两卡加间距等于左卡高度；有限内容无卡内滚动或溢出。
- 画布及实际绘图区随组合适配，无明显空白带、裁切、变形或重复采样；普通并排的原曲线风格和视觉基线保持。
- 在已校准范围内改变宽度、显示隐藏字段、正常轮询不产生高度反馈循环；范围外明确提供调整形态或结构的路径，不暗中裁切内容。
- 新形态原业务字段／动作不减少，标题操作与字体继续符合统一标准。此阶段设计者审图通过不等于用户美感认可。

证据：`structure-presentation/46-render/`。

## M66.47｜全部编辑路径与布局总览整合

目标：新能力融入现有操作，不产生两套交互或额外确认链。

任务树：

1. 接入添加、迁移、替换、拖放、改结构、镜像、调宽和显示设置，全部使用M66.45计划。
2. 更新适配提示和影响预览，明确区分自然排版、改变显式形态和不支持的组合。
3. 总览增加简洁形态标识并共用草稿；保持整行排序、选中与回到真实页面定位。
4. 核对空位保留／完成前整理、撤销／取消、键盘／触摸和焦点／手势互斥；不顺带扩大空位自动整理语义。

可测试达成标准：

- 明确标准连接从普通列移入上下槽位仍标准；上下对调、替换、镜像、隐藏后再添加均保留相应模块设置。
- 移动仍来源留空，替换仍隐藏目标且不交换；每个成功动作一次撤销完整恢复，不支持的动作无半提交。
- 不涉及形态改变的移动或自然增高不弹适配确认；需要改变形态时在一次现有影响预览内选择，不连续弹窗。
- 拖放、点击选择与键盘路径结果等价；调宽期间明确形态不改变，手势失效／resize／Escape取消未提交动作并清理。
- 总览标识与真实页面一致，缩略图高度不参与适配；两视图往返不修改文档，不重建业务读者。
- 编辑中业务控件仍受保护；整行排序只改顺序；完成前整理和整份取消遵守原规则，无新增常驻高度控制。

证据：`structure-presentation/47-interaction/`。

## M66.48｜当前候选完整回归与视觉校准

目标：证明新组合可用，且没有破坏已经认可的其他首页交互和业务。

任务树：

1. 当前源码类型检查、独立设计构建、旧业务源文件保护检查。
2. 五种结构、各模块已开放形态、旧auto兼容、新旧推荐及所有编辑路径回归。
3. 6种宽度×2主题×2语言基准、阈值附近及往返、异常和有限内容状态。
4. 鼠标／键盘／原生触摸、真实导航／表单动作、20次切换和资源释放。
5. 固定视口截图审阅、失败证据与优化记录；不能仅以几何或HTTP 200认定美观和完整业务通过。

可测试达成标准：

- 当前类型检查／设计构建通过；受保护原业务源文件与明确基线一致，设计构建适配有记录。
- 320／390／768／1024／1440／1920px、明暗、中英共24基准通过；首个混合形态组合、镜像、上下交换和普通布局均有针对性检查。
- 窄屏按列内顺序拆行，明确形态不丢信息；变宽恢复原结构与偏好；临界宽度无震荡，不生成布局历史。
- 网络正常／DNS或源异常／离线／缺地址／加载／失败、接口为空／失败／大量端口、其他模块缺服务等状态局部降级；限速服务缺失不隐藏库存。
- 原网络隐私及原DNS／源表单、端口详情，六组件原字段／页签／主动作／向导与提交字段回归通过；未知接口保持隔离，编辑不写业务。
- 20次形态／总览切换及排序撤销，无重复采样或监听增长，日志≤120、历史≤30；后台停止适用读取，实际卸载后计时器／观察器／监听器／浮层及滚动锁清理。
- 桌面和手机真实PNG均审阅，分别记录几何结果与设计者视觉结论；新例图不能覆盖或伪装旧失败。

证据：`structure-presentation/48-review/`。
