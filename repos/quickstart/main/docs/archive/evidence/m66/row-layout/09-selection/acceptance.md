## 自检与优化记录

交互脚本：`docs/product/ui-design/row-layout-interaction-review.cjs`。检查真实指针分隔拖动、键盘比例、预设、网络行高、三次缩窄/恢复、G列数和密度、F指针移动/缩放及恢复、三方案同十类卡片、手机替代控件。检查浏览器异常、外部请求及改变预览宽度后的卡片内部溢出。人工选择单独保持pending。

1. 第一次优化：原CSS Grid隐式轨道的内容最小高度使卡片超出指定行高，缩窄后的连接卡位置错误。用`minmax(0,1fr)`与显式`min-height:0`允许卡片按行尺寸收缩，不改测试。失败报告和诊断图保留为`first-interaction-report.json`、`first-width-diagnostic.png`。
2. 第二次优化：摘要列数断点与CSS列数断点统一；中宽应用区收紧内距；短连接卡收紧状态与字段间距。加强宽度变化检查，真实内容不得超出卡片。交互检查通过后，最终视觉复跑发现手机三条设备摘要占348px，超过340px卡片，失败报告为`third-round-input-visual-failure.json`。
3. 第三次优化：单列设备摘要除宽度外同时参考可用高度；紧凑卡显示两条，达到370px显示三条；不裁切权限说明，不放宽溢出断言。最终重跑结果与源码标识记录在上级`status.md`。

截图：`R-controls-desktop.png`、`R-narrow-preview.png`、`G-three-columns.png`、`F-move-resize.png`、`R-phone-controls.png`，每次完整检查均以本次服务构建为准。
