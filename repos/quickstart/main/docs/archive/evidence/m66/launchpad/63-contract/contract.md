# M66.63 契约与基线

起点ca6718d；范围为独立Vue原型。规则1.7 R18B～D及本轮计划共同定义：8/35及24/120仅前者约束首页；安装不自动固定；同ID只一项；已固定应用卸载保留名称和原因。旧0/1/6/8/24项ID、顺序、显示偏好不迁移重写。

入口实体保留来源、身份、目标；首页仅ID序列；完整库合并来源及保存的不可用项。刷新和过滤只是投影，不能写首页。工具与内置动作沿用，软件中心仍负责软件包安装卸载。

事务：布局、收藏、链接表单互斥。收藏恢复默认只改草稿，保存才替换首页序列；不删除链接。链接表单取消无写入；删除链接需确认，并原子清理其首页引用。链接新增默认不固定；已满24时明确禁止勾选固定但可仅存到库。64自定义链接，48项每页，全库搜索；HTTP(S)、名称64字、地址2048字、内置图标，不外访。

来源排序：工具/内置固定次序，安装目录按首次观察保持次序，新项追加；首页固定先按用户序列显示；非固定历史条目不无限留存，仅保留当前来源与已保存引用。错误保留最后快照，未知不误标卸载；成功缺失才标卸载。不存在或不安全入口可看原因，禁止跳转。

保护：sources.json冻结当前web源码，仅5个已有启动台文件可变；新文件限入口库、链接表单和验证。默认五行、图表、非应用形态、原业务、系统菜单、设计服务脚本均禁止变动。
