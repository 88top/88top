# 自然高度与系统信息双形态：M66.38～M66.43

2026-10-16。用户认可并授权连续实施。源码起点`8a12d35`，工作区开始时干净。范围仍是5180隔离Vue原型；复用原Vue/CSS、数据与业务表单，不改正式首页、左侧菜单、路由器或发布资产。唯一交互基线更新为[规范1.3](quickstart-home-layout-interaction-spec.md)R25～R30，原业务清单继续以[六组件业务基线](quickstart-home-business-widgets-alignment.md)为准。

## 已确定的设计契约

1. 先按宽度／位置／显式偏好选形态，再按有限内容自然布局，最后同排拉伸等高。实际DOM高度不是自动形态或列表容量的输入，不回写布局文档。
2. 系统信息沿用稳定ID `system`；`summary`显示紧凑概览，`standard`显示完整信息，`auto`按普通槽宽度及上下小槽角色推荐。普通槽宽560px分界已在M66.42以真实预览滑杆559／560／561px往返验证，<560紧凑、≥560完整；指定完整形态在普通窄槽仍完整展示、自然增高，不擅自改成摘要；不因此开放完整形态进入上下小槽。
3. 普通行不使用旧height像素约束；上下小卡按各自内容分配，合计含间距与相邻大卡等高。比例字段仅保留旧文档兼容，不再作为上下空间约束。流量图自身可视高度保持原320px（手机300px）及原曲线；不得因邻卡内容而拉伸曲线。若同排其他显式完整内容更高，外框可自然增高，图表可视区仍固定。
4. 当前原型文档升级schemaVersion 2，兼容旧rows／v1，保留稳定ID、行顺序、列宽、显式形态及旧height／split供恢复和旧对照使用；新增行高语义，普通行content、含图表行chart。迁移不写设备、不改真实存储；未知版本拒绝且保留输入。读回不擅自改显式形态。
5. 内容边界：设备沿用宽槽最多6／中槽4／窄槽3项；应用常用最多6、图标最多3行；DNS首页2项、端口首页2项；磁盘首页按原顺序最多3项（根盘／普通／RAID合并计数），共享首页最多2条SAMBA；完整详情仍用原组件显示全量。首页说明显示数量、总量和未显示异常，不能将隐藏条目误报为不存在。服务固定页签及系统完整字段不删减。
6. 标题区至多一个主要操作和必要更多菜单。原业务入口、包检查及原向导不改目标；新增完整内容入口进更多，移除重复底部详情按钮。状态／权限解释可以保留在底部，但不混为业务操作栏。
7. 缺失／失败局部呈现，原代码已知零值口径问题独立记录，不借视觉改造偷偷重定义。窗口变化只派生实际形态，不写偏好或历史；显式变更、移动替换及必要形态确认仍是一次可撤销事务。
