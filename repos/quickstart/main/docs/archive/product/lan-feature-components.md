# M71 局域网功能组件：统一入口与独立状态

2026-10-22 用户认可方案，进入实施。已检索现有编号，未发现M71；本阶段不复用M66编号。视觉沿用[局域网设置交互](lan-settings-interaction-refinement.md)及首页淡雅底面、业务点彩，不改变系统菜单。

## 目标与业务规则

1. 局域网设置分区导航旁始终提供“功能组件”。设备限速、浮动网关和设备详情的就近入口打开同一组件面板，可定位对应项目。
2. 固定登记智能设备限速、兼容限速、浮动网关，不建立任意插件平台。Bandix仍仅为现有规则迁移来源，不推荐新安装。
3. 业务能力状态、各组件安装/运行/兼容状态、当前执行方式分别读取。兼容限速可用不隐藏智能组件的安装入口；缺组件不阻断设备清单、联网权限、地址等独立功能。
4. 未安装→查看并安装；已安装未运行→查看并启用（仅有明确安全启用动作的组件）；异常→原因与重新检查；不兼容→原因；已就绪→设置/明确切换。浮动网关启用仍走既有配置预览，不一键改变职责/VIP。
5. 原生select只选择可用执行方式。卡片展示当前方式及推荐组件的简短状态/就近入口；组件面板提供安装详情和确认。具体包名、空间门槛和可能的包脚本服务影响在确认时显示。
6. 安装、启用、选择/切换三个动作分开；安装/启用不改当前执行方式，不应用网络策略，不迁移Bandix规则。切换仍进入原限速设置影响预览与确认。包安装钩子可能启动组件，应诚实提示。
7. 安装、重试、关闭、切换分区不丢失未提交草稿/待确认计划。组件面板只刷新观察值；不得调用全页load覆盖表单。状态失败不伪造未安装，HTTP200业务失败不能当成功。
8. 操作预检与确认保留，阻止重复点击和并发队列重复安装；安装结果未确认时先检查状态，不自动重复提交。关闭面板不表示取消已提交的系统操作。读取有截止、卸载清理、无常驻全页轮询。
9. 面板采用右侧抽屉，窄屏全宽，44px目标、焦点进入/约束/返回、Escape关闭、背景滚动锁、主题与中英适配；没有全页组件告警或新增竞争导航页。组件抽屉挂载到页面顶层，显式复用局域网语义颜色变量，避免LuCI内容祖先的堆叠上下文压住弹层；不修改原生菜单。绘制遮挡验收不能仅依赖inert生效时的命中结果。

## 实现边界

- 独立有界组件状态GET，共用现有capability-action预检/执行链路，组件目标固定白名单；修正device_speed_limit安装检查为原生组件自身状态，兼容方式单独描述。
- 前端一个组件状态/操作客户端和一个复用抽屉；设置与设备详情只接入入口和观察刷新，不重写DHCP、路线、限速、断网、规则迁移事务。
- 新功能权限按真实root会话核验，兼容旧后端时说明不可用并可重试，不推测安装状态。
- `.244` 为开发和操作验证目标。`.1` 本阶段仅低频串行读取与页面核对，不以此前一次后端更新授权推导安装/启用/网络写授权。

## 任务树与验收

M71.1：独立组件契约、状态与预检修正；测试覆盖eqos可用而native缺失/禁用/异常、并发、结果未确认、确认取消、不自动切换、opkg/APK包装器边界。

M71.2：统一入口、复用抽屉、就近引导与显式切换；覆盖三组件各状态、草稿/计划保留、关闭/重开、安装与启用分离、导航/键盘/滚动、手机/中英/主题。

M71.3：本地Go/前端类型/针对性及全量相关测试、正式构建；冻结提交、部署`.244`、真实登录态验收、资源/配置/进程保护与截图审查。真实状态与浏览器投影证据区分，缺失实装场景不能伪报通过。

每个产品候选最多三轮优化，失败证据不覆盖。证据目录：`docs/archive/evidence/m71/feature-components/`。通过后继续下一步；重要语义或三轮仍失败只暂停依赖部分。
