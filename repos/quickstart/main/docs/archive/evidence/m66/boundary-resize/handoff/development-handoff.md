# M66.50 开发交接

唯一产品基线：`docs/archive/product/quickstart-home-layout-interaction-spec.md` 1.5 R37～R40。任务树见`docs/archive/product/quickstart-home-boundary-resize-m66-50.md`。旧1.4禁止手动高度的部分已被用户认可的新方案替代，不倒改历史验收。

数据与解析：`OrderedRow.minHeight?`是用户指定的最小行空间，`Column.upperShare?`是上槽位占比；缺失为自动。保留原height/split兼容资料但不激活。v3可选字段有有限值、范围与列槽位数校验；迁移不把旧尺寸当成新偏好。派生最低尺寸不进入文档、推荐形态或列表容量。

实现：`rowSizing.ts`负责尺寸约束；`useNaturalSizing.ts`在已有渲染DOM上合并读取自然最低需求，测量前临时撤销用户分配、同步读取后恢复，不克隆业务组件或增加采样。既有容器观察器、布局／偏好／数据变化及页面操作触发合并RAF；后台不测量、卸载取消。`OrderedHome.vue`提供选中行的三种手柄与恢复自动，共用原文档计划、历史及取消入口。上下手势固定总高度，底边调整空间；显式空间使原ECharts真实容器伸展。

手势：主指针、3px移动阈值；键盘左右调宽、上下调空间。无变化不写历史，一次完整拖动一次历史。Escape、blur、pointercancel、resize、视图切换中断。拖动完成／取消后的合成点击在主容器捕获阶段消费，新指针和键盘激活不被吞掉；未增加全局点击监听器。模块移动、整行排序与尺寸手势互斥。

结构：镜像移动整列及分配偏好，整行排序只改顺序；重建结构保留行最小空间、清除旧列分配。移动／替换沿用模块唯一、来源留空、目标隐藏及形态偏好规则。完成前保守整理不跨行合并。小屏实际拆卡时忽略宽屏尺寸意图，不改写文档；同一模块仍只有一份业务实例。

当前是隔离Vue原型，源码指纹及公开资产见`candidate.json`，自动化见`../optimization-2/`。构建通过但保留原组件CSS calc／deep语法警告，未顺手改业务源码。正式业务集成前须显式设计布局存储／版本兼容，并在真实数据、字体、设备性能预算下重验测量成本和异步内容变化；本轮不能替代实机或长期观察。
