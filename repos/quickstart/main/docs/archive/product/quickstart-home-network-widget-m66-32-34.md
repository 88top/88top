## M66.33｜组件与交互

任务树：

1. 连接标准／摘要共用业务模型、完整详情和隐私控制。
2. IPv4／IPv6分别显隐，60秒后隐藏，切形态／关闭详情／隐藏页／卸载清理。
3. 接回设备管理、DNS配置及软件源配置；直接复用原表单，合成写入仅内存。
4. 独立接口标准／摘要、端口详情和接口配置入口；列表有界且完整入口可达。
5. 接入模块库、显示设置、响应式及原布局编辑保护；共享读取，不新增同义API。

验收：N06原连接字段／入口完整可达；N07地址隐私与计时清理正确；N08原表单校验／取消／成功／失败流程有证据；N09接口详情原字段完整且手机／键盘可用；N10布局编辑期间不会意外写业务。证据：`docs/archive/evidence/m66/network-widgets/33-interaction/`。
