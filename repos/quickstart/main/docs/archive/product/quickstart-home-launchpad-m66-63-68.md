# M66.63～M66.68：完整应用启动台

状态：用户已认可方向并授权M66.63～68连续实施；本文件保留任务树与验收目标，[实际阶段状态](../evidence/m66/launchpad/status.md)单独维护。编号接续M66.62，无重复。代码起点为`ca6718d`，原263组证据属于上一候选，不能代替本轮当前构建验收。

唯一首页规则继续维护在[交互规范](quickstart-home-layout-interaction-spec.md)；公共外观沿用[统一视觉标准](quickstart-home-widget-visual-standard.md)。M66.63先修订应用条款，明确“完整入口库”与“首页常用”的关系，其他布局及业务规则保持。

## 已认可的产品方向与本轮范围

| 层次 | 职责 | 数量与变化规则 |
| --- | --- | --- |
| 首页应用与工具 | 用户精选的常用入口 | 最多固定24项；当前八工具默认及网格／启动条显示偏好保留 |
| 点击全部的启动台 | 系统工具、内置功能、有效已安装应用、自定义链接 | 同ID只显示一次；全量可访问，不按首页容量截断；新来源不自动固定到首页 |
| 软件中心 | 安装、更新、卸载 | 保留原入口；启动台不另建软件包管理流程 |

“全部”默认选中全部来源，使用较宽浮层、图标与名称为主的统一网格。搜索及全部／应用／工具／链接轻量筛选放在顶部；内置功能归入工具筛选，业务类型与原动作仍保留。首页常用先按原顺序展示，其他入口稳定排列；新入口追加，不因刷新重排已有入口。排序是启动台的派生显示，不自动修改首页常用顺序。

系统工具与有权限、有效入口的已安装应用直接可找；元数据不含有效入口时给出说明，不能生成假跳转。已保存的卸载／未知项仍可在完整视图访问原因。不同对象操作明确区分：取消首页固定只改常用集合；删除自定义链接只删用户入口及其固定引用；卸载软件仍到软件中心。

添加自定义链接采用名称、HTTP(S)地址、项目内图标选择及可选“同时固定到首页”；同时固定默认关闭。普通浏览点击即启动，工具详情与编辑操作按需打开，不在每个图标旁常驻多组按钮。沿用当前首页编辑器完成常用排序、移除、撤销及保存／取消，不增加一套竞争的首页排序机制。

本轮继续只做5180隔离Vue原型，目录与链接配置在预览会话内存中模拟，导航保留、刷新恢复示例；不接真实持久化、不更改左侧菜单、不改行布局核心、不访问／写入路由器、不打包发布或推送。已有API的读取失败映射空数组、正式ACL与真实安装入口仍属正式集成前置。

为使资源边界可测试，本计划建议原型预算：自定义链接最多64项，启动台单页最多48个图标，超过时使用可访问的分页，搜索先作用于完整库再分页。首页常用24项与上述预算分别计数；分页不截断来源数据。预算在M66.63冻结，若调整须写明新数值及对应边界用例，不能留下无界渲染或静默丢项。

## M66.63：统一产品契约与当前基线

目标：使入口身份、首页固定、完整目录、删除及显示容量只有一套可执行解释。

任务树：

- 核对当前HomeApplications、共享目录、稳定宿主、原八工具及首页编辑器；冻结当前源码／资源和同条件截图。
- 修订唯一规范中的R14／R18／R18A；区分入口实体、来源快照、用户自定义链接与首页固定ID序列。
- 明确默认合并顺序、去重、来源变化、无效／无权限入口、恢复默认及三个编辑任务的边界。
- 固定名称／地址／图标、同地址提示、新页打开、容量／分页预算及旧收藏兼容；建立允许修改与保护清单。

验收标准：

1. 用“首页8项、完整库35项”“首页24项、完整库120项”“同ID来自两处”“已固定应用卸载”四组场景可推导唯一结果。
2. 已保存的0／1／6／8／24项保持原ID、顺序与显示偏好，新默认不覆盖已有数据。
3. 新增到完整库、固定／取消固定、编辑链接、删除链接、恢复默认、安装／卸载逐项说明影响对象；取消不会留下半份变更。
4. 首页24、自定义链接上限、单页渲染上限各自明确；超限有说明，超过一页仍能访问全部。
5. 左侧菜单、默认五行、图表、其他控件及原业务动作有冻结保护；计划与已完成状态明确分开。

证据位置：`docs/archive/evidence/m66/launchpad/63-contract/`。

## M66.64：统一入口库与首页固定分离

目标：所有来源能进入同一份完整库，首页只引用其中的精选入口。

任务树：

- 定义并归一化工具／内置／安装应用／用户链接来源，稳定ID与来源状态分开。
- 合并与去重，建立完整库查询、稳定排序、跨完整库搜索及分页投影。
- 保留独立的首页固定ID序列、24项约束与旧收藏兼容；不将整份目录塞进首页。
- 复用单一目录owner、缓存与主动重试；区分加载／空／错误／无权限／无入口，不增加扫描或轮询。

验收标准：

1. 完整库0／8／35／120项均可逐项访问，跨页计数与ID集合一致，单页不超过冻结预算。
2. 同ID不重复，名称改变不产生新入口；疑似同地址提示复用，不擅自合并不同目标或权限的对象。
3. 模拟新安装应用、目录重排、失败后恢复，首页固定序列和布局文档不变；新可用入口可在全部找到。
4. 目录失败不变为空库；已保存入口保留身份与最后已知名称，未知不误标卸载或运行中。
5. 旧六项与24项收藏读取兼容；错误恢复后同ID复用原位置，安装状态不被当作运行状态。

证据位置：`docs/archive/evidence/m66/launchpad/64-catalog/`。

## M66.65：宽浮层启动台与图标网格

目标：点击全部立即看到完整图标库，视觉与操作都比管理列表直观。

任务树：

- 将当前分类列表升级为右侧内容区内的宽浮层，保留稳定宿主与原页面焦点。
- 实现图标＋名称网格、顶部搜索及全部／应用／工具／链接筛选，默认全部；软件中心保持单一入口。
- 按实际容器适配桌面约6～8列、平板4列、手机2～3列；名称最多两行并保留完整名称访问，使用现有字号与浅深主题。
- 实现单一纵向滚动、分页、搜索无结果及状态区域；键盘／触摸、Escape、焦点圈定及恢复。

验收标准：

1. 一次点击全部即可看见混合来源；35项逐一可达，同ID无重复，无须逐个分类才能找到用户添加的入口。
2. 搜索和筛选作用于完整库，跨页项能被搜到；筛选不改保存顺序，清空条件恢复完整视图。
3. 1440／1280／1024／768／390／320px不遮挡标题／搜索／关闭，左右菜单预留区保持；无横向溢出或嵌套滚动。
4. 普通态点击图标执行正确原动作／设计目标；不误进入编辑或触发安装。鼠标、触摸及键盘能完成搜索、打开和关闭。
5. 同条件桌面、平板、手机浅深截图通过设计者审图；保留原字体与图标基线，主要触摸目标至少44px。最终主观美感仍由用户确认。

## M66.66：自定义链接与清楚的固定／删除操作

目标：用户可添加自己的服务或网站，完整库扩展与首页精选互不混淆。

任务树：

- 添加／编辑链接表单：名称、HTTP(S)地址、内置图标、打开方式说明、默认关闭的同时固定选项。
- 保存后完整库立即可找到；图标、名称、地址通过同一入口对象供首页与启动台使用。
- 区分取消首页固定与删除自定义链接；删除已固定链接时清楚说明同时移除首页引用，不触及软件或服务。
- 对草稿实现保存／取消、关闭／Escape、校验、重复提示、容量边界及恢复默认的保护。

验收标准：

1. 添加NAS链接→关闭再开全部→搜索并启动目标；未勾固定时首页项数、顺序、高度意图和布局文档不变。
2. 勾选固定且有余量时，完整库与首页引用同ID；首页已有24项时仍可仅添加到完整库，第25个固定须明确拒绝，不能默默忽略已选选项。
3. 编辑名称／地址／图标后ID、首页位置不变；取消与Escape均不修改已保存对象。
4. 取消固定后链接仍在全部；删除链接后其首页引用一并清理，其他入口不受影响；恢复默认首页常用不删除自定义链接库。
5. 空名称、错误地址、不支持协议与冻结容量上限＋1不能保存；合法HTTP(S)与中英文长名称可保存。按当前建议预算测试64项通过、第65项明确阻止。
6. 原型只预览目标与打开方式，不探测地址、不抓取外网图标、不访问真实服务；图标／地址缺失采用明确回退或校验。

证据位置：`docs/archive/evidence/m66/launchpad/66-custom-links/`。

## M66.67：状态、编辑互斥与资源回归

目标：目录变化、跨屏和多种编辑任务不造成入口丢失、错写或后台任务增长。

任务树：

- 将完整库接入现有首页编辑器，固定与常用排序共用既有逻辑；首页布局、常用编辑、链接表单互斥，草稿归属清楚。
- 覆盖错误／无权限／加载／空、卸载／无入口／恢复，以及首页容量之外的不可用入口。
- 检查缩屏、换主题、关闭、Escape、取消手势和离开页面；稳定宿主不因响应式行重建丢草稿。
- 核验分页与历史预算、20次开关／搜索／筛选／编辑循环，后台停止、真正卸载及异步响应过期处理。

验收标准：

1. 安装自动进入全部但不固定；卸载与失败按不同状态保留已保存入口，首页容量之外也能查看原因；恢复不另建重复ID。
2. 三个编辑任务不能同时操作同一份已保存数据，保存／撤销只影响所属任务；链接删除引起的固定清理作为一次明确变更。
3. 桌面变手机只取消未提交拖动，保留面板与已有草稿；关闭和返回不残留inert、滚动锁或失效焦点。
4. 120项分页后全部可访问，渲染和历史有界；20次交互循环不增加读取owner、监听器或采样任务，日志≤120、局部历史≤30。
5. 单一安装目录读取与既有图表／业务读取保持；后台与实际卸载后无新增请求或遗留手势／计时器，无真实设备写入。

证据位置：`docs/archive/evidence/m66/launchpad/67-states-resources/`。

## M66.68：完整候选验收与5180交付

目标：交付同一当前构建的漂亮、完整、可重复体验的启动台，供用户集中确认。

任务树：

- 冻结当前源码及公开资源，执行新场景与适用旧业务／布局检查，修订被新规则替代的断言并保留旧收藏兼容。
- 六宽度×中英文×浅深主题24组矩阵，补普通浏览、搜索、分页、链接表单、常用编辑、异常和鼠标／触摸／键盘关键任务。
- 复验八工具、11控件、原图表绘制、行排序／放置／尺寸、源代码保护及资源清理。
- 输出规则→实现→检查→证据映射、失败与优化记录、正式开发交接和人工体验卡；保持自有5180服务可访问。

验收标准：

1. “首页8项／完整35项”“首页24项／完整120项”“添加链接但不固定”“固定后取消固定”“编辑与删除已固定链接”“目录错误／恢复”“第24项不可用仍可达”均有当前浏览器证据。
2. 六宽度／两语言／两主题无非预期溢出、遮挡、缩字或菜单侵占；当前主要视图截图完成设计者审图，关键触摸目标与焦点操作通过。
3. 原工具行为、首页显示偏好、默认五行、原图表和其他业务保护检查通过；不以HTTP200、DOM存在或历史263组代替本候选验收。
4. 控制台、关键请求、加载／空／错误状态、资源循环和卸载检查通过；所有未通过项保留原始证据。
5. 公开5180资源与实际受测源码／构建哈希一致；标记为技术通过、等待用户审美与易用性确认。正式设备、持久化、打包与24小时观察不在本轮通过范围。
