# M66.50 人工体验任务卡

入口：[完整连接＋紧凑端口](http://192.168.9.19:5180/?layout=ordered&preset=network-stack&scenario=business-all)。刷新加载当前候选。

1. 点“自定义首页”。第一行选中，左／右之间、右侧两卡之间、整行底边各有一个手柄。其他行点击卡片空白区域或布局入口可选中；普通浏览不显示手柄。
2. 先拖右侧中间手柄。默认高度由完整内容撑开，两卡可能都已到最低高度；应就地提示可拉高整行，不能把整行意外拉长或压掉IPv4／IPv6／DNS。
3. 拉整行底边向下增加空间，再上下拖右侧中间手柄。两卡重新分配空间，行总高不变；左侧真实曲线随行高变化。左右手柄继续调整列宽。
4. 试撤销、Escape取消拖动。在行布局里“恢复自动高度与分配”，再撤销恢复；整页取消应恢复进入编辑前的布局。一次完整拖动只需撤销一次。
5. 选中手柄，用方向键调整；触屏拖动手柄，卡片空白处滑动仍能滚动页面。缩到手机后分隔线消失、内容自然展开；回宽屏恢复原尺寸偏好。
6. 使用顶部设计预览切“左右镜像”“上下反转”，再分别体验；错误／旧后端／服务缺失场景只影响对应内容，不应改写布局、隐藏设备清单或强迫切换形态。

请重点判断：三个手柄的位置与方向是否自然、默认最小高度提示能否理解、分配空间后是否美观、恢复自动是否容易找到。当前技术自检不能代替你的体验确认。

边界：合成数据、内存草稿，刷新恢复示例；手动最小高度最高1600px，内容需求可自然超过它；未接正式用户存储、路由器或发布流程。
