# 正式业务开发交接

唯一产品规则为交互规范1.7 R18B～D；任务与范围见M66.63～68计划。技术状态以当前候选报告及handoff-review.json为准，不能用早期263组或旧构建资源替代。

分层：HomeApplications保留首页呈现、原收藏草稿／拖动编辑与稳定宿主；launcherCatalog拥有单一来源读、取消／过期保护、来源状态与最后快照；launcherLibrary合并来源与固定引用，完成完整库查询、48项分页和64用户链接事务；LauncherLinkForm只负责链接草稿与校验。原卡片形态、默认五行、其他组件、原业务动作与系统菜单均不改。

首页最多固定24个ID，与完整库／自定义链接预算分别计数。当前来源按稳定顺序合并，固定ID优先；已保存不可用入口保留并说明原因。用户链接采用独立稳定ID，改名或改地址不换ID；删除链接及固定引用作为一次事务。布局编辑、收藏编辑、链接表单互斥；展示排序／查询不写首页顺序。重复地址仅提示，不自动合并权限或目标不同的入口。

本轮目录为合成示例，收藏和链接为内存状态。HTTP(S)链接只展示目标和未来新页打开方式，不访问外网、不抓取favicon或上传图标。已安装应用只说明安装与有效入口，不宣称服务正在运行。测试中的权限和错误为模拟响应。

正式集成前置：将真实/app/install-list/读取失败与空数组区分；按真实ACL判定入口可见与操作可用；保存版本化用户链接与固定ID序列，保证删除引用原子性并兼容旧收藏；由统一动作分发器处理可信路由／本机工具／安全外链，HTTP(S)外链正式使用noopener/noreferrer；复验真实来源去重、固件能力、并发版本冲突及持久化恢复。不得直接将当前合成目录或内存store作为业务数据库。

链接ID使用user-link:独立命名空间，与允许的软件包名字分离；当前预览序列只适用于刷新清空的内存会话，正式持久化必须使用可跨会话保持唯一的ID生成／分配机制，不能直接复制重置的序号。保存后按返回ID定位到实际链接页并聚焦；完整库查询或分页不修改首页收藏顺序。

资源：不开新轮询，不探测用户地址，目录只有一个读取owner，单页最多48DOM图标、最多64用户链接／24首页固定；日志120／局部撤销30。已卸载引用和错误快照按规则保留，非固定历史来源不无限累计。原业务router模块导入会创建一组固定beforeunload/popstate监听；它们不是本轮新增，正式原型宿主拆分可以另行评估，不由本次修改原路由。

本轮不证明实机API、路由器资源、软件包安装、前后端兼容、持久化或24小时观察；这些均需新的正式集成候选证据。人工审美确认独立。
