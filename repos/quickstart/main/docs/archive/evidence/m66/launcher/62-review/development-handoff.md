# 快捷启动台：产品与正式开发交接

唯一产品规则：[交互规范1.6 R14／R18／R18A](../../../../product/quickstart-home-layout-interaction-spec.md)。本轮任务树：[M66.57～62](../../../../product/quickstart-home-launcher-m66-57-62.md)。默认五行、11控件身份、各形态能力、行排序与边界操作继续沿用；左侧系统菜单不在Quickstart修改范围。

## 已实现的分层

| 职责 | 设计源码 | 边界 |
| --- | --- | --- |
| 稳定入口定义、默认值、内存收藏 | homeApplications.ts | widgetId=applications与入口ID分开；八默认只用于初始化／主动恢复，保存最多24项 |
| 元数据归一化 | launcherMetadata.ts | 对应AppInstalled的name/title/title_en/description/entry；按ID去重、保留缺入口安装项；安装不等于运行 |
| 单目录读取与状态 | launcherCatalog.ts | 一次会话共享owner；首次／场景切换／主动重试，无轮询；错误／无权限为未知，不能当卸载；不自动收藏 |
| 应用显示契约 | widgetPresentation.ts应用分支 | 保存数、显示容量、实际列数分开；半宽八项4×2、窄卡2×4，保留显式行数／启动条；其他组件解析未改 |
| 卡片与全部面板 | HomeApplications.vue及CSS | 共用字号／主题／连体按钮；有限首页，不做卡内滚动；软件中心沿原store/pages/store目标 |
| 稳定面板宿主 | launcherBrowserHost.ts | 复用页尾应用入口实例，卡片请求打开；跨响应式行重建仍保留编辑草稿，来源焦点失效时恢复到当前入口 |
| 直接网格与手势 | LauncherFavoriteGrid.vue | 静止容器捕获指针；开始时冻结逻辑槽位，动画不参与落点；一次完整拖动一次局部历史；键盘／触摸等价 |
| 草稿事务 | HomeApplications.vue | 历史≤30；添加／移除／拖动／恢复默认只改草稿；保存与取消独立于布局事务；两个编辑器互斥 |
| 原业务动作适配 | LauncherToolAction.vue | 直接挂载原内网／DNS／源／沙箱Vue表单；固件与终端／日志／维护保留原目标／选项／能力语义 |
| 设计专用传输与清理 | launcherFixtures.ts、fixtures.ts、useLauncherTimers.ts、vite.design.config.ts | 合成AppInstalled、模拟内存写；换地址／重启明确拒绝；原表单延迟任务卸载取消；正式构建不加载此配置 |

## 正式集成前置

- 先修现有`backend/modules/app/routes.go`将读取失败映射空数组的语义，验证目标固件真实安装目录与ACL。只接一个权威目录，不同时轮询LuCI和Go两份安装状态。
- 本原型目录全为合成。元数据入口、端口、跨域、安装能力和用户权限必须在目标版本真实核验；当前原型不会安装、卸载或启动任何应用。
- 收藏当前为会话内存，导航返回保留、刷新恢复示例。正式持久化的用户／路由器作用域、版本并发、迁移与权限另行定义；旧收藏不得被新默认覆盖。
- 把稳定面板宿主放在正式首页生命周期内，不能放进响应式槽位。生产设置API与真实动作应替换设计传输；不能把合成接口或模拟拒绝直接发布。
- 原始业务处理器均未改。内网提交／沙箱重启仅验证原表单与预览拒绝／清理；不宣称真实网络配置、设备安装、IPK/APK或限速数据面通过。24小时观察仍按原约定独立延期。

## 人工确认

从5180默认首页进入“应用与工具→更多→编辑快捷入口”。验证添加一款应用、拖至第二位、移除一项、撤销、保存再开；体验手机／桌面、全部分类搜索、零项、24项、卸载／未知状态。技术检查与设计者审图不代替用户的美感和易用性确认。
