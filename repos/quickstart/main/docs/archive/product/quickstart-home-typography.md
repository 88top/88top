# 首页原型共享字体规范

2026-10-16。用户要求在网络连接卡恢复原字体后，继续统一其他首页组件的字体与字号。适用于当前有序首页原型；正式业务组件、历史比较页和系统菜单不在本次修改范围。

## 原版依据与共同字阶

原首页Card.vue：标题16px／600，768px以下标题14px。Docker、磁盘、存储服务、下载、远程、系统等正文14px，容量／说明／标签12px；原网络流量标题16px、图例12px。实际baseline页面计算字体为`Arial, "Microsoft YaHei", sans-serif`。

| 信息角色 | 标准 | 窄屏／窄卡 |
|---|---|---|
| 卡片标题 | 16px／600 | 14px／600 |
| 正文、名称、常规值 | 14px | 13px |
| 辅助说明、标签、单位、次级操作 | 12px | 12px |
| 摘要标题 | 14px／600 | 14px／600 |
| CPU／内存／数量等关键数字 | 保留原指标字号 | 沿用组件既有指标呈现 |

“统一”表示相同信息层级使用相同字阶，并保留主次。摘要减少信息数量，不以9～11px字体塞入标准信息。流量图继续复用原业务组件和图表，只统一外层字体、标题与图例等DOM文字。

## 共享实现

[homeTypography.css](../../../web/src/design/homeTypography.css)集中定义字体栈及字阶，由OrderedHome最后加载；选择器限制于`.ordered-home`和当前网络详情弹层，不覆盖系统菜单或历史页面。显式font-size覆盖用于消除既有模块CSS和布局CSS中的9～11px及!important差异。未来修改应更新这套角色规则，不再各卡片单独微缩文字。

范围：网络流量、网络连接、网络接口、应用与工具、局域网设备、系统、磁盘、存储服务、Docker、下载、远程；覆盖标准、摘要、应用网格／启动条和对应应用／网络详情面板。布局编辑工具继承共同字体栈，保留原编辑密度，不重做编辑交互。

字阶变化不改变设备身份、状态解释、服务能力、权限、请求／采样频率、导航或偏好事务。应用网格仍遵循82px单元格、单／双／三行及既有容量契约；字体增长通过调整行内间距容纳，不增加隐式模块或修改用户行高。不能以裁切关键信息或无界增高来让测试通过。

## 本轮任务树与验收

1. 原版与现状核对：原Card及各业务组件源码／当前浏览器计算样式，对照字体、标题、正文与辅助层。
2. 共享规则实施：定义字阶，覆盖11模块与摘要／应用形态，保留历史页及菜单边界。
3. 当前构建自检：逐模块读computed style；320／390／768／1440／1920、中英文、深浅主题检查；覆盖三列、上下组合、应用多行、设备／服务异常与长文本。
4. 交互回归与交付：应用／设备导航、显示设置、撤销、网络隐私／详情；原业务源文件保护，更新5180及当前资源指纹。

验收：标准同角色字号一致；实际字体栈与原版相同；辅助文字不低于12px；无横向溢出、关键控件覆盖或卡片竖向越界；应用显示数量和用户布局不因字体变化而改写；历史页面和系统菜单原样。最多三次优化，检查证据保留，人工美观确认单独记录。
