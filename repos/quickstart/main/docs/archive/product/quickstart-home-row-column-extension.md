# R有序布局：多列与列内堆叠建议

后续确认与实施：用户已回复“同意，继续”，有限结构和五模板获授权。当前原型已在M66.10实现，实际行为与限制见 [完整R规格](quickstart-home-ordered-prototype-spec.md)，当前验证见 [M66.10](../evidence/m66/row-layout/10-interactions/acceptance.md)。以下保留当时建议推导；完整视觉仍待M66.12验收。

2026-10-15。用户已明确选择R有序自定义布局；本文件回答后续“一行三列”和“左一张、右上下两张”的产品问题。以下扩展是建议，未获最终确认，未改变5180当前实现。官方先例及其配置/可视化边界见 [专项研究](quickstart-home-nested-layout-research.md)。不引入新的并行产品基线，补充现有行布局计划。

## 推荐边界

采用“有序行 → 1～3个分栏 → 卡片”的有限结构。分栏可以装一张卡，也可在两分栏布局中装上下两张卡；首轮不支持分栏里再次左右拆分或任意递归嵌套。用户看到的是图示布局模板与卡片位置，不需要操作布局树。

推荐模板：整行一张、两张并排、三张并排、左大右上下、左上下右大；四卡两列上下作为可复用规则的后续备选，不必默认暴露更多组合。模板决定槽位结构，不绑定业务内容。用户可替换/移动卡片、调整列宽和允许的高度；不得重复同一业务模块。标准上下比例先提供50/50与60/40等档位，不为首版引入无限自由高度。

一行三列是现有行权重模型自然扩展。当前原型的扩展服务行已是Docker/下载/远程三列，三者最小宽度均280px，间距18px，总计至少876px内容宽度；这只证明三列代表样例，不是完整自定义三列编辑器。网络/设备等异构组合必须另按自身最小宽度计算。

## 对齐与高度预算

普通两/三卡行仍是每张卡等高。混合行改为每个分栏的外框同高；堆叠列满足“上卡高度＋间距＋下卡高度＝整行高度”。不要为了堆叠而给分栏再画一层可见卡片背景、标题与边框，正常浏览只保留业务卡片外观和统一间距；分栏边界只在编辑时出现。

最小可行行高为各列最小高度需求的最大值；堆叠列需求是两个子卡最小高度之和再加间距。当前注册表连接/系统均为260px，间距18px，现有组件组合至少538px，不能硬塞进320px网络行，更不能偷偷撑大原图或裁掉重要信息。

对希望放入320px行的紧凑摘要卡，必须另定义与验证新的尺寸契约，并把协议详情/完整系统字段转到已有详情入口；错误与权限说明仍须可达。紧凑卡验收前不能宣称该组合可用。高度不足时编辑器说明原因，提供换紧凑呈现、换卡或另起一行；增加行高只能由用户明确选择，首页不因读到长字段自动扩大。

## 编辑交互

先选布局缩略图，再选槽位卡片。列间拖动分隔线调整横向比例；堆叠列内部控制调整上下比例。选中卡片与选中整行有清楚区别，不同时出现多层手柄。

拖动落点明确标为替换/交换、移到上方或下方、另起一行；用户长时间悬停不能自动制造嵌套结构。提供按钮移动、模板和比例选项作为键盘/触屏替代。普通态隐藏所有布局控件。结构变换进入草稿，取消/撤销恢复原结构，应用仍仅影响原型内存；真实保存留给正式开发。

## 窄屏顺序

按实际内容宽度与子卡最小宽度适配，不按整个窗口判断。三列可以按原顺序拆为2＋1，再单列；两分栏堆叠不够宽时整列按顺序下移，保证列内上下关系。

左A右B/C的阅读顺序为A→B→C；左A/B右C为A→B→C，采用列优先。DOM、键盘焦点及屏幕阅读顺序与此一致，不用视觉order单独重排；编辑时提供手机预览。窄屏使用卡片自身推荐高度，不保留桌面整列固定高度。变宽恢复用户分组/比例；不跨组补洞、不因实时数据更新搬位置。

## 架构取舍与后续验收

现有PreviewRow.cards为平数组，只能表示同排卡；列内上下堆叠需要显式分栏结构，不能仅新增CSS绝对坐标。建议仍用Vue＋CSS Grid，固定深度的行/列/卡片数据、横纵权重、模块尺寸契约及集中布局协调器；不预先引入任意递归树、碰撞引擎或第三方拖拽库。布局变化只改变容器，不改变模块身份、数据源或采样任务。

相对成本判断：三列为低增量；有限上下堆叠为中等增量，工作主要在紧凑卡、拖放意图、撤销/取消、临界响应式和可访问性；任意递归嵌套为高复杂度，增加选中层级、跨层拖动、删除父容器和移动阅读顺序等问题。这是基于当前源码的工程判断，不是第三方产品性能实测。

M66.10若采纳扩展，先把以上模板、紧凑卡支持表、横纵最小尺寸与顺序规则加入任务树，再实现。验收须增加三列与左右堆叠的实际外框对齐误差≤1px、子卡无溢出、非法高度阻止、模板切换无卡片丢失/重复、取消/撤销、键盘/触屏替代、窄屏三次往返恢复；M66.11再覆盖主题/语言/状态和临界宽度。原M66.8/9通过记录不替代这些新增能力验收。
